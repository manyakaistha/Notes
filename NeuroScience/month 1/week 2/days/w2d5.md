## 2. Topic 1: The Complete End-to-End Python Laboratory

We simulate a Brain-Computer Interface (BCI) designed to detect cognitive relaxation (Alpha dominance). The pristine cortical rhythm is heavily corrupted by sweat drift, mains hum, sensor noise, and a massive blink.

### Code Implementation (`end_to_end_pipeline.py`)

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.signal import butter, filtfilt

# ==========================================
# STEP 1: BIOLOGICAL REALITY & DIGITIZATION
# ==========================================
np.random.seed(42)
fs = 250  # 250 Hz sampling rate
duration = 4.0  # 4 seconds
t = np.linspace(0, duration, int(fs * duration), endpoint=False)  # 1000 samples

# Simulated relaxed neural state: Dominant 10 Hz Alpha (12 uV), weak 20 Hz Beta (2 uV)
true_neural_signal = 12.0 * np.sin(2 * np.pi * 10.0 * t) + 2.0 * np.sin(2 * np.pi * 20.0 * t)

# ==========================================
# STEP 2: CONTAMINATION (NOISE & ARTIFACTS)
# ==========================================
# 1. Slow sweat/galvanic drift (0.2 Hz, 20 uV amplitude)
sweat_drift = 20.0 * np.sin(2 * np.pi * 0.2 * t)
# 2. 50 Hz power-line mains hum (8 uV amplitude)
line_noise = 8.0 * np.sin(2 * np.pi * 50.0 * t)
# 3. High-amplitude eye blink artifact centered at t = 2.0 s (80 uV peak)
blink = 80.0 * np.exp(-((t - 2.0)**2) / 0.05)
# 4. Stochastic amplifier thermal noise
sensor_noise = np.random.normal(0, 2.0, len(t))

# Compound observed raw signal (what the hardware records)
raw_observed_eeg = true_neural_signal + sweat_drift + line_noise + blink + sensor_noise

# ==========================================
# STEP 3: PREPROCESSING (TWO-STAGE FILTERING)
# ==========================================
def apply_bandpass(data, low_cut, high_cut, sfreq, order=4):
    """Applies zero-phase Butterworth band-pass filter."""
    nyq = 0.5 * sfreq
    b, a = butter(order, [low_cut / nyq, high_cut / nyq], btype='band')
    return filtfilt(b, a, data)

def apply_notch(data, notch_freq, sfreq):
    """Applies surgical 50 Hz zero-phase notch filter."""
    nyq = 0.5 * sfreq
    b, a = butter(4, [(notch_freq - 1.0) / nyq, (notch_freq + 1.0) / nyq], btype='bandstop')
    return filtfilt(b, a, data)

# Pipeline: Notch 50 Hz -> Band-pass 1-30 Hz
eeg_notched = apply_notch(raw_observed_eeg, 50.0, fs)
eeg_clean = apply_bandpass(eeg_notched, 1.0, 30.0, fs)

# ==========================================
# STEP 4: FEATURE EXTRACTION (TIME & FREQUENCY)
# ==========================================
# Time-domain features
feat_mean = np.mean(eeg_clean)
feat_var = np.var(eeg_clean)
feat_amp = np.max(eeg_clean) - np.min(eeg_clean)

# Frequency-domain band powers (via bandpass variance)
alpha_filtered = apply_bandpass(eeg_clean, 8.0, 12.0, fs)
feat_alpha_power = np.var(alpha_filtered)

beta_filtered = apply_bandpass(eeg_clean, 13.0, 30.0, fs)
feat_beta_power = np.var(beta_filtered)

# ==========================================
# STEP 5: AI-READY REPRESENTATION MATRIX
# ==========================================
ai_input_vector = np.array([feat_mean, feat_var, feat_amp, feat_alpha_power, feat_beta_power])
ai_input_matrix = ai_input_vector.reshape(1, -1)  # Reshape to [1 sample, 5 features]

# Diagnostics & Quantitative Verification
print(f"Observed raw shape:  {raw_observed_eeg.shape} (1,000 samples)")
print(f"AI input vector shape: {ai_input_vector.shape}")
print(f"AI input matrix shape: {ai_input_matrix.shape} ([Samples x Features])")
print("\nFinal AI Feature Vector [Mean, Variance, P2P Amplitude, Alpha Power, Beta Power]:")
print(np.array2string(ai_input_vector, precision=3, suppress_small=True))
print(f"\nFiltered Mean (DC residual): {feat_mean:.3f} uV")
print(f"Clean Target Variance:       {12**2/2 + 2**2/2:.2f} uV^2 | Filtered Signal Variance: {feat_var:.3f} uV^2")
print(f"Alpha Power vs Beta Power:   {feat_alpha_power:.3f} uV^2 vs {feat_beta_power:.3f} uV^2 (Ratio: {feat_alpha_power/feat_beta_power:.1f}x)")
```

### Quantitative Output & Interpretation

```text
Observed raw shape:  (1000,) (1,000 samples)
AI input vector shape: (5,)
AI input matrix shape: (1, 5) ([Samples x Features])

Final AI Feature Vector [Mean, Variance, P2P Amplitude, Alpha Power, Beta Power]:
[  0.161 130.636  65.337  70.142   2.457]

Filtered Mean (DC residual): 0.161 uV
Clean Target Variance:       74.00 uV^2 | Filtered Signal Variance: 130.636 uV^2
Alpha Power vs Beta Power:   70.142 uV^2 vs 2.457 uV^2 (Ratio: 28.5x)
```

1. **Matrix Dimensions:** 1,000 raw temporal measurements are compressed into an observation matrix of shape `(1, 5)`. For a dataset of $W$ time windows and $C$ channels, the resulting dataset matrix is `(W, C * 5)`.
2. **Mean Residual ($0.161\mu\text{V}$):** The high-pass filter attenuated the $20\mu\text{V}$ sweat drift down to nearly zero. The small positive offset stems from finite window boundary transients and the asymmetric 80 µV blink pulse.
3. **The Artifact Residual Reality:** The theoretical variance of the uncontaminated neural oscillation was $\frac{12^2}{2} + \frac{2^2}{2} = 72 + 2 = 74.00\mu\text{V}^2$. The filtered signal exhibits a variance of $130.636\mu\text{V}^2$, and peak-to-peak amplitude is $65.337\mu\text{V}$. 
   - **Crucial Lesson:** Filtering attenuated drift and mains hum, but **could not eliminate the eye blink**. Because the blink is a non-stationary transient whose Fourier energy bleeds across $1\text{–}30\text{ Hz}$, frequency filtering left significant residual ringing and distortion around $t = 2.0\text{ s}$.
4. **Dominant Biological Feature:** Measured Alpha Power ($70.142\mu\text{V}^2$) heavily exceeds Beta Power ($2.457\mu\text{V}^2$), preserving the biological relaxation pattern ($28.5\times$ ratio).

## 3. Topic 2: Real Data Considerations & File Formats

When transitioning to empirical clinical datasets (e.g., PhysioNet, BCI Competition):
- **File Formats:** Data arrives in standardized formats:
  - `.edf` (European Data Format)
  - `.bdf` (BioSemi 24-bit Data Format)
  - `.vhdr` / `.eeg` / `.vmrk` (BrainVision header, data, and event marker files)
- **Library Ecosystem:** Specialized neuroimaging packages like **MNE-Python** must be used for loading and metadata parsing:
  ```python
  import mne
  raw = mne.io.read_raw_edf("recording.edf", preload=True)
  ```
- **Metadata is Load-Bearing:** Underneath the file wrapper lies a NumPy array of shape $\text{[Channels} \times \text{TimeSamples]}$. However, the metadata dictating channel montage locations, units, sampling frequency, impedance, and event markers is vital.
- **Unit Pitfall:** MNE stores voltages internally in **Volts** ($\text{V}$), whereas synthetic models typically use **microvolts** ($\mu\text{V}$). Multiplying by $10^6$ is required to avoid scaling mismatches in power computations:
  $$1\text{ V} = 10^6 \, \mu\text{V}$$

## 4. The Week 2 Mastery Test & Authoritative Solutions

The following comprehensive evaluation tests mastery of the entire signal processing pipeline:

### Part A — Concepts

#### 1. Fundamental Difference: Sampling Rate vs. Signal Frequency
- **Sampling Rate ($f_s$):** A property of the **recording equipment**. Answers: *"How frequently does the hardware measure the physical potential?"* Measured in samples per second ($\text{Hz}$). Example: $f_s = 250\text{ Hz}$ means the ADC captures a value every $4\text{ ms}$.
- **Signal Frequency ($f$):** A property of the **underlying phenomenon**. Answers: *"How rapidly does a specific component of the measured potential oscillate?"* Measured in cycles per second ($\text{Hz}$). Example: $f = 10\text{ Hz}$ means the biological neural population alternates between polarity states 10 times per second ($T = 100\text{ ms}$).

$$\boxed{\text{Sampling Rate} = \text{Hardware Measurement Speed}} \quad \Big\vert \quad \boxed{\text{Signal Frequency} = \text{Physical Oscillation Speed}}$$

#### 2. Duality of the Band-Pass Filter
A low-pass filter establishes an upper cutoff ($f < f_{\text{high}}$). A high-pass filter establishes a lower cutoff ($f > f_{\text{low}}$). A band-pass filter enforces both constraints concurrently:
$$f_{\text{low}} < f < f_{\text{high}}$$
It attenuates slow baseline drifts below $f_{\text{low}}$ while attenuating high-frequency noise above $f_{\text{high}}$, preserving only the intermediate frequency window.

---

### Part B — Numerical Reasoning

#### 3. Array Shape: 128 Channels, 5 Minutes, 200 Hz Sampling
1. **Total Duration in Seconds:**
   $$D = 5\text{ minutes} \times 60\text{ seconds/minute} = 300\text{ seconds}$$
2. **Number of Samples per Channel ($N$):**
   $$N = f_s \times D = 200\text{ samples/sec} \times 300\text{ sec} = 60,000\text{ samples}$$
3. **Number of Spatial Channels ($C$):**
   $$C = 128\text{ channels}$$
4. **Final NumPy Array Shape:**
   $$\boxed{(128, 60000)} \quad \text{or} \quad [128 \text{ Channels} \times 60,000 \text{ Time Samples}]$$
   *Total numerical values:* $128 \times 60,000 = 7,680,000\text{ floating-point entries}$.

---

### Part C — Plot & Data Interpretation

#### 4. Diagnostic Interpretation: Mean = 0.0001 Across 1,000 Windows
- **Scientific Verdict:** This **does not** imply biological brain death or inactive tissue.
- **Physical Explanation:** The mean corresponds to the direct current ($0\text{ Hz}$ DC) offset. A mean of $0.0001\mu\text{V}$ across all windows indicates that a **high-pass filter** (e.g., $f_c = 0.5\text{–}1.0\text{ Hz}$) or **baseline detrending / DC removal** was applied during preprocessing. 
- Vibrant oscillatory neural dynamics (e.g., a massive $10\mu\text{V}$ Alpha or Beta oscillation) naturally oscillate symmetrically about zero, yielding a sample mean of approximately zero while possessing significant variance and band power.

### Part D — Pipeline Reasoning (Driver Fatigue BCI)

#### 5. BCI System Design Scenario
*Hypothesis:* As a driver falls asleep, slow Delta waves ($1\text{–}4\text{ Hz}$) increase dramatically, while fast Beta waves ($15\text{–}30\text{ Hz}$) decrease.

```
Raw Multichannel EEG (Driving Simulator)
          │
          ▼
Stage 1: Artifact Screening & Epoch Rejection
   - Reject high-amplitude steering motion pops (> ±100 µV)
   - Flag ocular blink intervals via frontal EOG channels / ICA
          │
          ▼
Stage 2: Frequency Filtering
   - 0.5–40 Hz 4th-order zero-phase Band-pass (preserves 1–4 Hz Delta and 15–30 Hz Beta)
   - 50/60 Hz Notch filter (suppresses simulator electrical interference)
          │
          ▼
Stage 3: Spectral & Feature Extraction
   - Compute PSD via Welch's method across sliding 2-second windows
   - P_Delta = ∫[1 to 4 Hz] PSD(f) df
   - P_Beta  = ∫[15 to 30 Hz] PSD(f) df
   - Relative Powers & Delta/Beta Ratio: R = P_Delta / (P_Beta + ε)
          │
          ▼
AI Classification Model (Fatigue vs. Alert)
```

1. **Anticipated Simulator Artifacts:**
   - *Ocular:* Frequent blinking, saccades checking mirrors, slow eyelid closure (low frequency $1\text{–}3\text{ Hz}$, overlapping Delta).
   - *Muscle (EMG):* Neck tension, grip clenching on steering wheel, jaw clenching (high frequency $20\text{–}100+\text{ Hz}$, overlapping Beta).
   - *Motion:* Head movement, mechanical vibration from simulator seat causing electrode pops.
   - *Power-Line:* 50/60 Hz mains interference from visual display rigs and computer hardware.
2. **Filter Cutoff Selection:**
   - **$0.5\text{–}40\text{ Hz}$ Band-Pass:** High-pass cutoff at $0.5\text{ Hz}$ removes sweat drift while preserving the entire $1\text{–}4\text{ Hz}$ Delta band; low-pass cutoff at $40\text{ Hz}$ preserves $15\text{–}30\text{ Hz}$ Beta while attenuating high-frequency muscle noise.
   - **$50\text{ Hz}$ / $60\text{ Hz}$ Notch:** Suppresses simulator electrical mains hum.
3. **Artifact Handling Strategy:**
   - High-amplitude eye blinks share frequencies with Delta ($1\text{–}4\text{ Hz}$). Therefore, **filtering alone cannot separate blinks from sleep Delta**. 
   - Implement **Independent Component Analysis (ICA)** to separate the ocular component, or use threshold-based **epoch rejection** on frontal channels to discard contaminated segments.
4. **Extracted Features for Machine Learning:**
   - **Absolute Delta Power:** $P_{\Delta} = \int_{1}^{4} \text{PSD}(f) \, df$
   - **Absolute Beta Power:** $P_{\beta} = \int_{15}^{30} \text{PSD}(f) \, df$
   - **Relative Band Powers:** $\frac{P_{\Delta}}{P_{\text{total}}}$ and $\frac{P_{\beta}}{P_{\text{total}}}$ to normalize for inter-subject impedance variations.
   - **Fatigue Index (Delta/Beta Ratio):**
     $$R_{\Delta/\beta} = \frac{P_{\Delta}}{P_{\beta} + \epsilon}$$
     (where $\epsilon = 10^{-6}\mu\text{V}^2$ prevents division by zero). As fatigue increases, $R_{\Delta/\beta}$ increases monotonically.

### Part E — Research Reading & Methods Critique

#### 6. Excerpt Analysis
> *"Continuous EEG was recorded using 32 Ag/AgCl electrodes. The data was digitized at 1000 Hz. Offline, the signals were downsampled to 250 Hz to reduce computational load, and a 4th-order Butterworth band-pass filter from 0.5 to 45 Hz was applied. 50 Hz line noise was deemed negligible due to the upper cutoff. Epochs containing voltage fluctuations exceeding $\pm 100\mu\text{V}$ were discarded to remove ocular artifacts. Alpha (8-12 Hz) band power was extracted for classification."*

1. **Conceptual Input Data Shape:**
   - Initial acquisition: `(32, 1000 * D)` where $D$ is duration in seconds.
   - Resampled shape: `(32, 250 * D)`. Because duration $D$ is unspecified in the excerpt, the exact sample count cannot be determined.
2. **Why They Deemed 50 Hz Line Noise Negligible:**
   - The upper cutoff of their band-pass filter is $45\text{ Hz}$. Because $50\text{ Hz} > 45\text{ Hz}$, 50 Hz line noise falls into the stopband.
   - **The Critical Research Nuance:** Filters do not possess infinite attenuation cliffs. A 4th-order Butterworth filter with $f_c = 45\text{ Hz}$ evaluated at 50 Hz retains an amplitude gain of approximately $0.250$ ($-12.06\text{ dB}$). That is, **$25\%$ of mains noise still leaks through**. Assuming line noise is negligible without verifying residual spectral power is an empirical flaw.

![Filter Attenuation at Mains Frequency](../assets/mains_attenuation.png)
**Figure 2.** Empirical forward-backward frequency response of the 4th-order 0.5–45 Hz Butterworth filter near the upper cutoff, demonstrating that 50 Hz line noise retains $0.250$ amplitude gain ($-12.06\text{ dB}$) rather than being completely eliminated.

3. **How Eye Blinks Were Handled:**
   - **They did NOT filter the blinks.** They utilized **amplitude-based epoch rejection**.
   - Any time window containing voltages exceeding $\pm 100\mu\text{V}$ was completely discarded from the training set. This preserves the remaining data without introducing filter ringing, but discards data volume.
