# W4D1: Neural Networks — Artificial Neurons, Forward Propagation, and Backpropagation

## 1. Executive Briefing

Week 4 transitions the *NeuroScience* vault from classical heuristic feature engineering to deep representation learning. Over Weeks 1–3, our decoding pipeline relied on manual heuristics: band-pass filtering continuous voltage traces, calculating summary statistics (mean, variance, Welch band powers), and training shallow classifiers ([[logistic-regression]], [[decision-tree]], [[support-vector-machine]]). While computationally transparent, manual feature extraction introduces a severe inductive bottleneck: it collapses complex oscillatory phase dynamics and non-linear spatiotemporal interactions into static summary vectors.

Today's module builds the mathematical and practical foundations of deep neural networks:
1. **The Artificial Neuron:** Formulating the parameterized affine mapping $z = w^T x + b$ and non-linear activation $\hat{y} = \sigma(z)$, while clarifying the sharp distinctions between artificial point-process abstractions and biological pyramidal biophysics.
2. **Forward Propagation:** Tracing deterministic tensor transformations and explicit dimension routing through multi-layer architectures.
3. **Loss Functions and Backpropagation:** Deriving the analytical gradient of binary cross-entropy loss with respect to weights and biases via the multivariable chain rule, executing a real numerical parameter update step on human EEG alpha-band features.
4. **Multi-Layer Perceptron (MLP):** Training a 2-layer neural network on 15 real sensorimotor features from Subject 1, implementing a leak-free validation-loss checkpoint selection protocol, and observing empirical generalization limits.

All analyses use verified data from the PhysioNet EEG Motor Movement/Imagery Dataset (`S001`, Runs 4, 8, 12; channels $C_3, C_z, C_4$).

## 3. Mathematical Foundations: The Artificial Neuron

### 3.1 Affine Logit Formulation

An [[artificial-neuron]] receives an input vector $x = [x_1, x_2, \dots, x_P]^T \in \mathbb{R}^P$. It applies a linear affine transformation parameterized by a weight vector $w = [w_1, w_2, \dots, w_P]^T \in \mathbb{R}^P$ and a scalar bias $b \in \mathbb{R}$:
$$z = w^T x + b = \sum_{j=1}^P w_j x_j + b$$
The scalar $z$ is termed the **affine logit** (pre-activation). The weights $w_j$ determine the sensitivity and polarity of the neuron's response to each feature, while the bias $b$ sets the baseline operating threshold when inputs are zero.

### 3.2 Non-Linear Activation Functions

To enable neural networks to model non-linear decision boundaries, the logit $z$ is passed through a non-linear [[activation-function]] $f: \mathbb{R} \to \mathbb{R}$:
$$a = f(z) = f(w^T x + b)$$
Without non-linear activations, any multi-layer sequence of linear operations collapses mathematically to a single affine map:
$$z^{(2)} = W^{(2)} (W^{(1)} x + b^{(1)}) + b^{(2)} = (W^{(2)} W^{(1)}) x + (W^{(2)} b^{(1)} + b^{(2)}) = \tilde{W} x + \tilde{b}$$
For binary classification, the output activation is the logistic sigmoid:
$$\hat{y} = \sigma(z) = \frac{1}{1 + e^{-z}} \in (0, 1)$$
where $\sigma'(z) = \sigma(z)(1 - \sigma(z)) = \hat{y}(1 - \hat{y})$. For hidden layers, the standard non-linearity is the Rectified Linear Unit (ReLU):
$$\text{ReLU}(z) = \max(0, z), \quad \frac{d}{dz}\text{ReLU}(z) = \begin{cases} 1 & \text{if } z > 0 \\ 0 & \text{if } z < 0 \end{cases}$$

### 3.3 Loss Function: Binary Cross-Entropy

For a ground-truth label $y \in \{0, 1\}$ and predicted probability $\hat{y} \in (0, 1)$, the **Binary Cross-Entropy (BCE) Loss** is defined as the negative log-likelihood:
$$L(y, \hat{y}) = - \left[ y \log(\hat{y}) + (1 - y) \log(1 - \hat{y}) \right]$$
When $y = 1$, $L = -\log(\hat{y})$, penalizing small predicted probabilities. When $y = 0$, $L = -\log(1 - \hat{y})$, penalizing large predicted probabilities.

### 3.4 Analytical Backpropagation on a Single Neuron

[[backpropagation]] calculates the exact gradient of the loss $L$ with respect to each parameter using the chain rule:
$$\frac{\partial L}{\partial w_j} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z} \cdot \frac{\partial z}{\partial w_j}$$
Evaluating each component:
1. $\frac{\partial L}{\partial \hat{y}} = - \frac{y}{\hat{y}} + \frac{1 - y}{1 - \hat{y}} = \frac{\hat{y} - y}{\hat{y}(1 - \hat{y})}$
2. $\frac{\partial \hat{y}}{\partial z} = \hat{y}(1 - \hat{y})$
3. $\frac{\partial z}{\partial w_j} = x_j, \quad \frac{\partial z}{\partial b} = 1$

Multiplying yields the elegant result:
$$\frac{\partial L}{\partial z} = \hat{y} - y$$
$$\nabla_w L = (\hat{y} - y) x, \quad \frac{\partial L}{\partial b} = \hat{y} - y$$
Under gradient descent with learning rate $\eta > 0$, the parameters are updated along the negative gradient:
$$w \leftarrow w - \eta (\hat{y} - y) x, \quad b \leftarrow b - \eta (\hat{y} - y)$$

> [!NOTE]
> **Biological Caveat:** An artificial neuron abstracts away action potentials, temporal ion conductances (Hodgkin-Huxley dynamics), dendritic spatial summation, neurotransmitter vesicular release, and refractory periods into a static scalar product. Furthermore, biological neural circuits do not possess symmetric feedback connections required to backpropagate scalar error gradients across synaptically separated layers (the "weight transport problem").

## 4. Laboratory 1: Single Gradient Step on Real Human EEG

We extract two real standardized features from Subject 1, Trial 0: $C_3$ alpha power ($x_1 = 1.3445$) and $C_4$ alpha power ($x_2 = 1.3485$), with target label $y = 1$ (`RIGHT_HAND`). We initialize $w = [0.60, -0.40]^T$, $b = 0.10$, and learning rate $\eta = 0.50$.

```python
import numpy as np
import pandas as pd

# 1. Read measured powers (uV^2); demonstration-only cohort scaling.
df = pd.read_csv('data/week3_features.csv')
cols = ['C3_alpha', 'C4_alpha']
raw = df.loc[0, cols].to_numpy(dtype=np.float32)
x = np.array([(raw[i] - df[c].mean()) / df[c].std()
              for i, c in enumerate(cols)], dtype=np.float32)
y = int(df.loc[0, 'target'])

# 2. Forward pass; standardized inputs and logits are dimensionless.
w = np.array([0.60, -0.40], dtype=np.float32)
b, eta = 0.10, 0.50
z0 = float(w @ x + b)
p0 = float(1 / (1 + np.exp(-z0)))
loss0 = -(y * np.log(p0) + (1-y) * np.log(1-p0))

# 3. Analytical gradient and joint weight/bias update.
grad = p0-y
w_new, b_new = w-eta*grad*x, b-eta*grad
z1 = float(w_new @ x + b_new)
p1 = float(1 / (1 + np.exp(-z1)))
loss1 = -(y * np.log(p1) + (1-y) * np.log(1-p1))
print(f'Target: {y}; standardized inputs: {x[0]:.4f}, {x[1]:.4f}')
print(f'Before: z={z0:.4f}, p={p0:.4f}, BCE={loss0:.4f}')
print(f'Gradients: dw={grad*x}, db={grad:.4f}')
print(f'After:  z={z1:.4f}, p={p1:.4f}, BCE={loss1:.4f}')
print(f'Loss reduction: {loss0-loss1:.4f}')
```

## 5. Laboratory 2: Multi-Layer Perceptron (MLP) on 15 Features

We extend single-neuron operations to a multi-layer network. We construct `CompactMLP`, a 2-layer network with 15 input features, 8 hidden neurons with ReLU activation, and 2 output logits:
$$h = \text{ReLU}(W^{(1)} x + b^{(1)}) \in \mathbb{R}^8, \quad \text{logits} = W^{(2)} h + b^{(2)} \in \mathbb{R}^2$$
Total trainable parameters: $(15 \times 8 + 8) + (8 \times 2 + 2) = 128 + 18 = 146$ parameters.

### 5.1 Experimental Protocol: Run Holdout on Subject 1

To evaluate generalization without leakage:
- **Training Set:** Run 4 (15 trials). `StandardScaler` is fitted strictly on Run 4.
- **Validation Set:** Run 8 (15 trials). Used exclusively for checkpoint selection.
- **Held-Out Test Set:** Run 12 (15 trials). Evaluated once using the checkpoint with the lowest validation loss.

```python
import torch
import torch.nn as nn
import torch.optim as optim

class CompactMLP(nn.Module):
    def __init__(self, in_features=15, hidden_dim=8, num_classes=2):
        super().__init__()
        self.fc1 = nn.Linear(in_features, hidden_dim)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(hidden_dim, num_classes)
        
    def forward(self, x):
        h = self.relu(self.fc1(x))
        return self.fc2(h)

# Training loop with validation checkpoint selection
model = CompactMLP(15, 8, 2)
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.02, weight_decay=1e-3)

best_val_loss = float('inf')
best_weights = None
best_epoch = 0
```

### 5.2 Critical Interpretation

The MLP rapidly achieves 100% training accuracy within 20 epochs, driving training loss down to 0.15. However, validation loss begins diverging after Epoch 2, and held-out test accuracy on Run 12 is only 40.0% (6/15 trials correct), performing below the 50% chance baseline.

This empirical result delivers an essential lesson in neural decoding:
1. **The Curse of Low Sample Size:** With only 15 training trials and 15 input features, an MLP with 146 parameters has sufficient capacity to memorize sample-specific noise patterns rather than generalizable sensorimotor desynchronization.
2. **Checkpoint Selection Protocol:** Without early stopping on validation loss, continuing training to epoch 40 would result in severe parameter overfitting to Run 4's baseline noise.
3. **Motivation for Inductive Bias:** Passing handcrafted feature vectors into dense fully connected layers discards temporal geometry. To decode continuous electrophysiology effectively, networks must incorporate structural inductive biases—specifically temporal convolutions that respect the local continuity of brain waves.

## 6. Daily Knowledge Checkpoint

### Question 1: Mathematical Gradient Equivalence
**Prompt:** Prove that for a single artificial neuron with logistic sigmoid activation $\hat{y} = \sigma(z)$ and binary cross-entropy loss $L$, the derivative with respect to the pre-activation logit is exactly $\frac{\partial L}{\partial z} = \hat{y} - y$. Explain why this functional form is computationally advantageous.

**Solution:**
The loss function is $L = - [y \log \hat{y} + (1 - y) \log(1 - \hat{y})]$. Differentiating with respect to $\hat{y}$:
$$\frac{\partial L}{\partial \hat{y}} = - \frac{y}{\hat{y}} + \frac{1 - y}{1 - \hat{y}} = \frac{-y(1 - \hat{y}) + (1 - y)\hat{y}}{\hat{y}(1 - \hat{y})} = \frac{-y + y\hat{y} + \hat{y} - y\hat{y}}{\hat{y}(1 - \hat{y})} = \frac{\hat{y} - y}{\hat{y}(1 - \hat{y})}$$
The logistic sigmoid derivative is $\frac{\partial \hat{y}}{\partial z} = \sigma(z)(1 - \sigma(z)) = \hat{y}(1 - \hat{y})$.
Applying the chain rule:
$$\frac{\partial L}{\partial z} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z} = \left( \frac{\hat{y} - y}{\hat{y}(1 - \hat{y})} \right) \cdot \left( \hat{y}(1 - \hat{y}) \right) = \hat{y} - y$$
The denominator $\hat{y}(1 - \hat{y})$ cancels out completely. This cancellation prevents numerical instability near saturating extremes ($\hat{y} \to 0$ or $\hat{y} \to 1$) and ensures the gradient magnitude is directly proportional to the linear prediction error.

### Question 2: Biological vs. Artificial Neurons
**Prompt:** Identify three fundamental biophysical properties of biological cortical neurons that are omitted in the standard artificial neuron model $y = f(w^T x + b)$.

**Solution:**
1. **Temporal Dynamics and Action Potentials:** Biological neurons communicate via discrete, millisecond-duration all-or-none action potentials (spikes) governed by voltage-gated ion channels ($Na^+, K^+, Ca^{2+}$). Artificial neurons emit continuous, time-invariant scalar activations.
2. **Non-linear Spatiotemporal Dendritic Integration:** Biological dendrites are active computational cables where excitatory and inhibitory postsynaptic potentials (EPSPs/IPSPs) undergo complex cable attenuation, shunting inhibition, and local dendritic NMDA spikes. Artificial neurons perform a simple, instantaneous algebraic sum.
3. **Metabolic Constraints and Dale's Principle:** Biological cortical neurons adhere to Dale's principle (a given neuron releases either excitatory transmitters like glutamate or inhibitory transmitters like GABA across all its axon terminals). In artificial neurons, a single unit can exhibit arbitrary positive and negative weights simultaneously, violating physiological constraints.

### Question 3: Overfitting and Validation Divergence
**Prompt:** In Laboratory 2, training loss continually decreased while validation loss increased after Epoch 2. Explain why this divergence occurs in small-sample EEG datasets and state the exact checkpoint selection rule applied.

**Solution:**
With $N_{train} = 15$ trials and $P = 15$ features, the model has more parameters (146) than degrees of freedom in the training sample. The optimizer easily finds weight configurations that fit idiosyncratic, run-specific noise and electrode impedance variations unique to Run 4. As optimization proceeds, the decision boundary contorts around these training points, destroying margin distance and inflating error on independent validation trials from Run 8. 

The checkpoint selection rule monitors validation loss $L_{val}^{(t)}$ at each epoch $t$, caches the model parameter state $\theta^{(t)}$ whenever $L_{val}^{(t)} < \min_{\tau < t} L_{val}^{(\tau)}$, and restores $\theta^{(t^*)}$ where $t^* = \arg\min_t L_{val}^{(t)}$ (Epoch 2, $L_{val} = 0.6708$) prior to final held-out testing on Run 12.
