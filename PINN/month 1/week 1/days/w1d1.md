## 1. Day 1 Overview & Daily Goals

Before implementing scientific machine learning models, we must formalize the fundamental object of study: the **continuous function**. In traditional deep learning (computer vision or NLP), data consists of discrete pixel grids or token sequences. In scientific machine learning and Physics-Informed Neural Networks (PINNs), the input data consists of continuous spatial-temporal coordinate vectors:

$$\mathbf{x} = (t, x_1, x_2, \dots, x_d)^T \in \Omega \subset \mathbb{R}^{d+1}$$

and the target output is a continuous physical field $u(\mathbf{x}) \in \mathbb{R}^m$ (e.g., velocity, pressure, temperature).

The primary goals of Day 1 are:
1. Distinguish independent continuous coordinate variables from dependent physical state fields.
2. Formalize mathematical functions as topological mappings between continuous metric spaces.
3. Understand how coordinate graphs represent multidimensional physical surfaces.
4. Implement coordinate evaluation grids and domain sampling in Python.

## 2. Prerequisite Diagnostic Checkpoint

Before proceeding, let us verify our mathematical vocabulary and vector foundations.

### Diagnostic Questions & Authoritative Solutions

#### 1. What constitutes an independent variable versus a dependent variable in continuum physics?
- **Independent Variables:** The coordinates specifying where and when an observation occurs (spatial coordinates $x, y, z \in \mathbb{R}^3$ and temporal coordinate $t \in [0, T]$). They vary freely across domain $\Omega$.
- **Dependent Variables:** Physical quantities whose values are determined by the location and time (e.g., temperature $T(t, \mathbf{x})$, fluid velocity $\mathbf{v}(t, \mathbf{x})$).

#### 2. What is the mathematical definition of a function $f: X \to Y$?
- A function is a binary relation between two sets $X$ (domain) and $Y$ (codomain) such that for every element $x \in X$, there exists a unique element $y = f(x) \in Y$. In continuum mechanics, $X$ is a compact subset of Euclidean space $\mathbb{R}^d$ and $Y = \mathbb{R}^m$.

#### 3. What does it mean for a function to be of class $C^k(\Omega)$?
- A function $f: \Omega \to \mathbb{R}$ is in $C^k(\Omega)$ if all partial derivatives of order up to and including $k$ exist and are continuous at every point in $\Omega$. If $k=0$, $f$ is continuous; if $k=\infty$, $f$ is smooth. Second-order differential equations require solutions in $C^2(\Omega)$.

#### 4. How does the dimensionality of input coordinates affect computational complexity in numerical grids?
- If each spatial-temporal axis is discretized into $N$ points, a $d$-dimensional coordinate domain requires $N^d$ grid points. For $d=4$ (3D space + time) and $N=100$, this demands $10^8$ mesh nodes, creating the **curse of dimensionality**.

## 3. Core Theory: Coordinate Spaces, Fields & Graphs

### 3.1 Scalar and Vector Fields
In physics, functions over space-time take two fundamental forms:
1. **Scalar Field:** Maps each coordinate point to a single real number:
   $$\Phi: \mathbb{R}^d \longrightarrow \mathbb{R}, \quad (x, y, z) \mapsto T(x, y, z)$$
   Examples: Temperature, electrostatic potential, pressure.
2. **Vector Field:** Maps each coordinate point to a vector of physical quantities:
   $$\mathbf{v}: \mathbb{R}^d \longrightarrow \mathbb{R}^d, \quad (x, y, z) \mapsto \begin{bmatrix} v_x(x, y, z) \\ v_y(x, y, z) \\ v_z(x, y, z) \end{bmatrix}$$
   Examples: Fluid velocity, gravitational force, electric field.

### 3.2 Coordinate Graphs and Level Sets
The **graph** of a scalar function $f: \Omega \subset \mathbb{R}^2 \to \mathbb{R}$ is the 2D surface embedded in 3D Euclidean space:

$$\text{Graph}(f) = \left\{ (x_1, x_2, z) \in \mathbb{R}^3 \;\middle|\; z = f(x_1, x_2), \; (x_1, x_2) \in \Omega \right\}$$

A **level set** (or contour line) of $f$ is the subset of domain coordinates that yield an identical scalar value $c$:

$$\mathcal{L}_c(f) = \left\{ (x_1, x_2) \in \Omega \;\middle|\; f(x_1, x_2) = c \right\}$$

Level sets are indispensable for visualizing isotherms (lines of constant temperature), isobars (lines of constant pressure), and equipotential surfaces.

## 4. Practical Laboratory: Coordinate Evaluation & Surface Slicing

### 4.1 Concept → Code → Output → Interpretation

#### 1. Concept
We construct a continuous 2D scalar potential field $\Phi(x_1, x_2) = x_1^2 + 2x_2^2 - \cos(\pi x_1)$ on $\Omega = [-2, 2] \times [-2, 2]$, sample it onto a discrete numerical tensor, and extract 1D coordinate slices to verify continuity.

#### 2. Code
```python
import numpy as np

# Define continuous function
def potential_field(x1, x2):
    return x1**2 + 2.0 * x2**2 - np.cos(np.pi * x1)

# Generate coordinate lattice
x1_coords = np.linspace(-2.0, 2.0, 5)
x2_coords = np.linspace(-2.0, 2.0, 5)
X1, X2 = np.meshgrid(x1_coords, x2_coords)

# Evaluate scalar field
Z = potential_field(X1, X2)

print("Coordinate Lattice Shape:", Z.shape)
print("Center Coordinate (x1=0, x2=0) Value:", potential_field(0.0, 0.0))
print("Corner Coordinate (x1=-2, x2=-2) Value:", potential_field(-2.0, -2.0))
print("\nEvaluated Field Matrix:")
for row in Z:
    print(" ".join(f"{val:6.2f}" for val in row))
```

#### 3. Output
```text
Coordinate Lattice Shape: (5, 5)
Center Coordinate (x1=0, x2=0) Value: -1.0
Corner Coordinate (x1=-2, x2=-2) Value: 11.0

Evaluated Field Matrix:
 11.00   7.00   7.00  11.00  19.00
  7.00   3.00   3.00   7.00  15.00
  5.00   1.00   1.00   5.00  13.00
  7.00   3.00   3.00   7.00  15.00
 11.00   7.00   7.00  11.00  19.00
```

#### 4. Interpretation
The evaluated numerical tensor represents the discrete sampling of an underlying continuous functional surface. At the origin $(0,0)$, $\Phi(0,0) = 0 + 0 - \cos(0) = -1.00$. At $(-2, -2)$, $\Phi = (-2)^2 + 2(-2)^2 - \cos(-2\pi) = 4 + 8 - 1 = 11.00$. Notice how the discrete matrix is merely a window into the continuous domain; in a PINN, neural networks evaluate points at arbitrary non-grid coordinates without interpolation error.

## 5. Daily Knowledge Mastery Checkpoint

### Problem 1: Domain Mapping Topology
**Question:** If a neural network $u_\theta: \mathbb{R}^2 \to \mathbb{R}$ takes inputs $(t, x)$ and predicts temperature $u$, what is the geometric dimension of its input domain versus the geometric dimension of its graph?  
**Authoritative Solution:**  
The input domain $\Omega \subset \mathbb{R}^2$ is 2-dimensional (time and one spatial coordinate). The graph of the network is the set of points $(t, x, u_\theta(t, x)) \in \mathbb{R}^3$, which is a 2-dimensional hypersurface (a manifold) embedded within a 3-dimensional Euclidean space.

### Problem 2: Slicing Multidimensional Fields
**Question:** Given the 3D velocity field $\mathbf{v}(x, y, z) = (y, -x, 2z)^T$, what is the physical meaning of setting $z = 0$?  
**Authoritative Solution:**  
Setting $z=0$ restricts the 3D vector field to the 2D equatorial plane $(x, y) \in \mathbb{R}^2$. On this plane, $\mathbf{v}(x, y, 0) = (y, -x, 0)^T$, representing a pure rigid-body rotation around the $z$-axis with zero vertical velocity.

### Problem 3: Tensor Geometry in PyTorch
**Question:** When training a neural network on $N=500$ collocation points in a 2D domain $(t, x)$, what must be the tensor shape of the input coordinates?  
**Authoritative Solution:**  
The coordinate tensor must have shape `[500, 2]`, where each row represents a coordinate pair $(t_i, x_i)$. Storing coordinates as flattened 1D arrays without batch dimensions causes broadcasting bugs in autodiff operations.
