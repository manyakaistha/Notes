## 1. Day 3 Overview & Daily Goals

Physical laws frequently specify how a quantity changes relative to its current state. When a physical system depends on a single independent variable (such as time $t$), the governing conservation equations are **Ordinary Differential Equations (ODEs)**.

The primary goals of Day 3 are:
1. Define ordinary differential equations, distinguishing order, degree, and linearity.
2. Formulate the canonical second-order linear ODE: the damped harmonic oscillator.
3. Prove why initial conditions ($u(0)=u_0, \dot{u}(0)=v_0$) are required to isolate a unique physical trajectory.
4. Implement numerical time integration using explicit Runge-Kutta solvers (`scipy.integrate.solve_ivp`).

## 2. Diagnostic & Previous-Day Verification

### Diagnostic Questions & Authoritative Solutions

#### 1. What differentiates an ODE from a PDE?
- An ODE involves derivatives with respect to a single independent variable $t \in \mathbb{R}$ (e.g., $\frac{d^2 u}{dt^2} + u = 0$).
- A PDE involves partial derivatives with respect to two or more independent variables (e.g., $\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}$).

#### 2. What is the order of the differential equation $\frac{d^3 u}{dt^3} + u \left(\frac{du}{dt}\right)^4 = \sin(t)$?
- The order is **3** (the highest derivative present is $\frac{d^3 u}{dt^3}$). The term $\left(\frac{du}{dt}\right)^4$ determines its degree and makes the ODE non-linear, but does not alter the order.

#### 3. Why cannot an ODE solver compute a unique solution without initial conditions?
- Differentiation is a many-to-one operation; taking derivatives eliminates additive constants ($dC/dt = 0$). Integrating an $n$-th order ODE yields an $n$-dimensional affine space of candidate solutions parameterized by $n$ arbitrary integration constants. Initial conditions fix these constants.

## 3. Core Theory: Ordinary Differential Equations & The Harmonic Oscillator

### 3.1 First-Order Systems and State-Space Representation
Any $n$-th order ODE can be converted into an equivalent system of $n$ coupled first-order ODEs. Consider the second-order equation:

$$\ddot{u} = f(t, u, \dot{u})$$

By defining the state vector $\mathbf{y}(t) = [y_1(t), y_2(t)]^T \equiv [u(t), \dot{u}(t)]^T$, we obtain the state-space system:

$$\frac{d}{dt} \begin{bmatrix} y_1 \\ y_2 \end{bmatrix} = \begin{bmatrix} y_2 \\ f(t, y_1, y_2) \end{bmatrix}$$

This canonical reduction enables standard numerical integrators (e.g., RK45) and neural network solvers to operate on uniform first-order formulations.

### 3.2 The Damped Harmonic Oscillator
Newton's second law for a mass $m$ experiencing a linear restoring force $-ku$ and viscous damping force $-c\dot{u}$ gives:

$$m \ddot{u} + c \dot{u} + k u = 0$$

Dividing by $m$:
$$\ddot{u} + 2\gamma \dot{u} + \omega_0^2 u = 0$$
where $\gamma = \frac{c}{2m}$ is the damping factor, and $\omega_0 = \sqrt{\frac{k}{m}}$ is the natural frequency.

## 4. Practical Laboratory: Numerical Integration of the Damped Oscillator

### 4.1 Concept → Code → Output → Interpretation

#### 1. Concept
We formulate the state-space representation of a damped harmonic oscillator ($m=1.0, c=0.8, k=16.0 \implies \gamma = 0.4, \omega_0 = 4.0$). Since $\gamma < \omega_0$, the system is underdamped with damped angular frequency $\omega_d = \sqrt{16.0 - 0.16} \approx 3.97995\text{ rad/s}$. We solve this initial value problem numerically using Scipy's `solve_ivp` across $t \in [0, 4]$ with $u(0)=1.0, \dot{u}(0)=0.0$.

#### 2. Code
```python
import numpy as np
from scipy.integrate import solve_ivp

# Define system parameters
m, c, k = 1.0, 0.8, 16.0
gamma = c / (2.0 * m)
omega0 = np.sqrt(k / m)
omega_d = np.sqrt(omega0**2 - gamma**2)

# First-order state space ODE: y = [u, v]
def harmonic_system(t, y):
    u, v = y
    dudt = v
    dvdt = -(c / m) * v - (k / m) * u
    return [dudt, dvdt]

# Integrate from t=0 to t=4
t_eval = np.linspace(0, 4, 9)
sol = solve_ivp(harmonic_system, [0, 4], [1.0, 0.0], t_eval=t_eval, rtol=1e-8, atol=1e-8)

# Analytical exact solution for verification
# u(t) = exp(-gamma t) * [cos(wd t) + (gamma / wd) * sin(wd t)]
u_exact = np.exp(-gamma * t_eval) * (np.cos(omega_d * t_eval) + (gamma / omega_d) * np.sin(omega_d * t_eval))

print("Time t:                 ", np.round(sol.t, 2))
print("Numerical u(t):         ", np.round(sol.y[0], 5))
print("Analytical u(t):        ", np.round(u_exact, 5))
print("Absolute Error:         ", np.round(np.abs(sol.y[0] - u_exact), 8))
```

#### 4. Interpretation
The high-order Runge-Kutta numerical integration matches the analytical underdamped solution to $10^{-8}$ absolute accuracy. The amplitude decays exponentially envelope $e^{-0.4 t}$, dropping from $1.0$ at $t=0$ to approximately $-0.20106$ at $t=4$. In Week 4, this exact dynamic oscillator will serve as our primary benchmark problem for training our first Physics-Informed Neural Network solver.

## 5. Daily Knowledge Mastery Checkpoint

### Problem 1: Critical Damping Ratio
**Question:** If $m=2\text{ kg}$ and $k=50\text{ N/m}$, what value of damping coefficient $c$ produces critical damping?  
**Authoritative Solution:**  
Critical damping occurs when the discriminant vanishes: $\gamma = \omega_0$.
$$\omega_0 = \sqrt{\frac{k}{m}} = \sqrt{\frac{50}{2}} = \sqrt{25} = 5\text{ rad/s}$$
$$\gamma = \frac{c}{2m} = 5 \implies c = 2m \cdot 5 = 2(2)(5) = 20\text{ N}\cdot\text{s/m}$$

### Problem 2: Transforming High-Order ODEs
**Question:** Convert the third-order non-linear ODE $\frac{d^3 u}{dt^3} + 2 \frac{d^2 u}{dt^2} + u \frac{du}{dt} - 5u = 0$ into a first-order state-space vector system.  
**Authoritative Solution:**  
Define state variables:
$$y_1 = u, \quad y_2 = \dot{u}, \quad y_3 = \ddot{u}$$
Their time derivatives are:
$$\dot{y}_1 = y_2$$
$$\dot{y}_2 = y_3$$
$$\dot{y}_3 = \frac{d^3 u}{dt^3} = 5u - u \frac{du}{dt} - 2\frac{d^2 u}{dt^2} = 5 y_1 - y_1 y_2 - 2 y_3$$
In vector form:
$$\frac{d\mathbf{y}}{dt} = \begin{bmatrix} y_2 \\ y_3 \\ 5y_1 - y_1 y_2 - 2y_3 \end{bmatrix}$$
