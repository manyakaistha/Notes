3. Implement vectorized batch matrix-multiplication operations in PyTorch.
4. Verify affine plane geometry computationally.

## 2. Prerequisite Diagnostic Checkpoint

### Diagnostic Questions & Authoritative Solutions

#### 1. What is an affine transformation versus a strictly linear transformation?
- A linear transformation satisfies $T(a\mathbf{x} + b\mathbf{y}) = a T(\mathbf{x}) + b T(\mathbf{y})$ and must map the origin to the origin ($T(\mathbf{0}) = \mathbf{0}$).
- An affine transformation is a linear transformation followed by a translation: $A(\mathbf{x}) = \mathbf{W}\mathbf{x} + \mathbf{b}$. When $\mathbf{b} \ne \mathbf{0}$, $A(\mathbf{0}) = \mathbf{b} \ne \mathbf{0}$.

#### 2. What is the geometric interpretation of the equation $\mathbf{w}^T \mathbf{x} + b = 0$ in $\mathbb{R}^d$?
- It defines a $(d-1)$-dimensional hyperplane. The weight vector $\mathbf{w}$ is the normal vector perpendicular to the hyperplane, and the signed perpendicular distance from the coordinate origin to the hyperplane is $d = \frac{b}{\|\mathbf{w}\|_2}$.

#### 3. Why cannot a single linear layer without activation solve non-linear problems?
- Composing multiple linear transformations yields another linear transformation: $\mathbf{W}_2(\mathbf{W}_1 \mathbf{x} + \mathbf{b}_1) + \mathbf{b}_2 = (\mathbf{W}_2 \mathbf{W}_1)\mathbf{x} + (\mathbf{W}_2 \mathbf{b}_1 + \mathbf{b}_2) = \mathbf{W}_{\text{eff}}\mathbf{x} + \mathbf{b}_{\text{eff}}$. Without non-linear activations, an arbitrary 100-layer network collapses mathematically to a single affine layer.

## 3. Core Theory: Vectorized Affine Operations in Batch Mode

### 3.1 Batch Processing Matrix Form
In scientific machine learning, we evaluate physical fields at hundreds or thousands of collocation points simultaneously. Let $\mathbf{X} \in \mathbb{R}^{N \times d_{in}}$ be a batch matrix containing $N$ coordinate points, each of dimension $d_{in}$. A linear layer containing $d_{out}$ neurons parameterized by weight matrix $\mathbf{W} \in \mathbb{R}^{d_{out} \times d_{in}}$ and bias vector $\mathbf{b} \in \mathbb{R}^{d_{out}}$ computes:

$$\mathbf{Z} = \mathbf{X} \mathbf{W}^T + \mathbf{1}_N \mathbf{b}^T \in \mathbb{R}^{N \times d_{out}}$$

In PyTorch, this is implemented as `nn.Linear(d_in, d_out)`.

## 4. Practical Laboratory: Vectorized Forward Projection & Hyperplane Slicing

### 4.1 Concept → Code → Output → Interpretation

#### 1. Concept
We construct a single artificial neuron mapping 2D spatial coordinates $(x_1, x_2)$ to a scalar output using PyTorch. We set manual weights $\mathbf{w} = [3.0, -4.0]^T$ and bias $b = 5.0$, pass a batch of 4 coordinates, and verify the analytical pre-activations and hyperbolic tangent activations.

#### 2. Code
```python
import torch
import torch.nn as nn

# Define manual single-neuron layer
neuron = nn.Linear(in_features=2, out_features=1, bias=True)
with torch.no_grad():
    neuron.weight.copy_(torch.tensor([[3.0, -4.0]]))
    neuron.bias.copy_(torch.tensor([5.0]))

# Coordinate test points: (0,0), (1,2), (-1,1), (2,-1)
coords = torch.tensor([
    [0.0, 0.0],
    [1.0, 2.0],
    [-1.0, 1.0],
    [2.0, -1.0]
])

# Compute affine pre-activation z and tanh activation
z = neuron(coords)
a = torch.tanh(z)

print(f"Weight Tensor:\n{neuron.weight.data}")
print(f"Bias Tensor:  {neuron.bias.data}\n")
print(f"{'Coord (x1, x2)':<18} | {'Pre-act z':<12} | {'Tanh Activation a':<18}")
print("-" * 52)
for i in range(len(coords)):
    c_str = f"({coords[i,0].item():.1f}, {coords[i,1].item():.1f})"
    print(f"{c_str:<18} | {z[i,0].item():<12.4f} | {a[i,0].item():<18.6f}")
```

#### 3. Output
```text
Weight Tensor:
tensor([[ 3., -4.]])
Bias Tensor:  tensor([5.])

Coord (x1, x2)     | Pre-act z    | Tanh Activation a 
----------------------------------------------------
(0.0, 0.0)         | 5.0000       | 0.999909          
(1.0, 2.0)         | 0.0000       | 0.000000          
(-1.0, 1.0)        | -2.0000      | -0.964028         
(2.0, -1.0)        | 15.0000      | 1.000000          
```

#### 4. Interpretation
Observe the second point $(1.0, 2.0)$: $z = 3(1.0) - 4(2.0) + 5.0 = 3 - 8 + 5 = 0.0000$. This confirms that coordinate $(1.0, 2.0)$ lies precisely on the zero-hyperplane separating boundary $3x_1 - 4x_2 + 5 = 0$, producing $\tanh(0) = 0$. At $(0,0)$, $z=5$ saturates $\tanh$ near $+1$; at $(-1,1)$, $z=-2$ produces $-0.964$. The neuron partitions the 2D spatial coordinate space into two half-spaces.

## 5. Daily Knowledge Mastery Checkpoint

### Problem 1: Parameter Count Calculation
**Question:** A fully-connected layer maps a 3D coordinate vector $(t, x, y)$ to 64 hidden neurons. What is the total number of trainable parameters in this layer?  
**Authoritative Solution:**  
The weight matrix has dimension $\mathbf{W} \in \mathbb{R}^{64 \times 3}$, yielding $64 \times 3 = 192$ weights. The bias vector has dimension $\mathbf{b} \in \mathbb{R}^{64}$, yielding $64$ biases.  
Total parameters = $192 + 64 = 256$ parameters.

### Problem 2: Affine Invariance
**Question:** If the input coordinates are shifted by a constant translation vector $\mathbf{x} \to \mathbf{x} + \mathbf{x}_0$, how must the neuron's bias $b$ be adjusted to keep the neuron's pre-activation invariant?  
**Authoritative Solution:**  
$$z_{\text{new}} = \mathbf{w}^T (\mathbf{x} + \mathbf{x}_0) + b_{\text{new}} = \mathbf{w}^T \mathbf{x} + \mathbf{w}^T \mathbf{x}_0 + b_{\text{new}}$$
To ensure $z_{\text{new}} = \mathbf{w}^T \mathbf{x} + b$, we require:
$$\mathbf{w}^T \mathbf{x}_0 + b_{\text{new}} = b \implies b_{\text{new}} = b - \mathbf{w}^T \mathbf{x}_0$$
