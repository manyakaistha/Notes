## Diagnostic Checkpoint & Prerequisites

1. **What does the Cybenko Universal Approximation Theorem (1989) prove, and what does it NOT guarantee?**  
   *Answer:* Cybenko proved that any continuous function $f \in C(\Omega)$ on a compact domain $\Omega \subset \mathbb{R}^d$ can be approximated to arbitrary accuracy $\epsilon > 0$ by a feedforward neural network with a single hidden layer and a continuous sigmoidal activation:
   $$\|f(\mathbf{x}) - u_\theta(\mathbf{x})\|_{\infty} < \epsilon$$
   Crucially, the theorem is an **existence theorem**: it does *not* guarantee that gradient descent will find the optimal parameters $\theta^*$, it does *not* bound the required width $M$ (which may be exponentially large), and it does *not* guarantee that derivatives of the network approximate derivatives of the target function.

2. **What is Spectral Bias (The Frequency Principle) in neural network training?**  
   *Answer:* Rahaman et al. (2019) and Xu et al. (2019) demonstrated that standard coordinate MLPs trained with gradient descent prioritize learning low-frequency Fourier components before high-frequency components. In the Fourier domain, the error at frequency $k$ decays as $\exp(-2 \lambda_k t)$, where the decay rate $\lambda_k \propto k^{-2d}$ shrinks rapidly as frequency increases. High-frequency physical features (shock waves, turbulence, thin boundary layers) converge exponentially slower than smooth background modes.

3. **In PyTorch tensor operations, what is the memory layout of an MLP coordinate forward pass?**  
   *Answer:* The input tensor has shape `[N_batch, d_in]`. Each linear layer computes $\mathbf{Z}^{(l)} = \mathbf{X}^{(l-1)} \mathbf{W}^{(l)} + \mathbf{b}^{(l)}$, performing a matrix multiplication `[N, d_{l-1}] @ [d_{l-1}, d_l] -> [N, d_l]`. The bias `[1, d_l]` is broadcast across the $N$ batch rows.

## 1. Mathematical Theory: MLP Architecture & Spectral Bias

### 1.1 Multi-Layer Perceptron Formalism

Let an $L$-layer coordinate network $u_\theta: \mathbb{R}^{d_{\mathrm{in}}} \to \mathbb{R}^{d_{\mathrm{out}}}$ be defined by parameters $\theta = \{\mathbf{W}^{(l)}, \mathbf{b}^{(l)}\}_{l=1}^L$. The forward propagation algorithm evaluates:
$$\mathbf{z}^{(1)} = \mathbf{W}^{(1)} \mathbf{x} + \mathbf{b}^{(1)}, \quad \mathbf{a}^{(1)} = \sigma(\mathbf{z}^{(1)})$$
$$\mathbf{z}^{(l)} = \mathbf{W}^{(l)} \mathbf{a}^{(l-1)} + \mathbf{b}^{(l)}, \quad \mathbf{a}^{(l)} = \sigma(\mathbf{z}^{(l)}), \quad l = 2, \dots, L-1$$
$$u_\theta(\mathbf{x}) = \mathbf{W}^{(L)} \mathbf{a}^{(L-1)} + \mathbf{b}^{(L)}$$


### 1.3 The Neural Tangent Kernel (NTK) & Convergence Dynamics

The mathematical mechanism behind Spectral Bias in coordinate networks is rigorously explained by **Neural Tangent Kernel (NTK)** theory (Jacot et al., 2018; Wang et al., 2021).

In the infinite-width limit, an MLP trained via continuous-time gradient flow evolves under a deterministic, stationary kernel $\mathbf{K}_{\mathrm{NTK}}(\mathbf{x}, \mathbf{x}') \in \mathbb{R}^{d_{\mathrm{out}} \times d_{\mathrm{out}}}$ defined by the inner product of gradient Jacobians:
$$\mathbf{K}_{\mathrm{NTK}}(\mathbf{x}, \mathbf{x}') = \sum_{p=1}^P \frac{\partial u_\theta(\mathbf{x})}{\partial \theta_p} \left( \frac{\partial u_\theta(\mathbf{x}')}{\partial \theta_p} \right)^T$$

Let $\mathcal{D} = \{\mathbf{x}_i\}_{i=1}^N$ be the set of collocation points. The empirical NTK Gram matrix $\mathbf{K} \in \mathbb{R}^{N \times N}$ has spectral eigendecomposition:
$$\mathbf{K} = \sum_{k=1}^N \lambda_k \mathbf{v}_k \mathbf{v}_k^T$$
where $\lambda_1 \ge \lambda_2 \ge \dots \ge \lambda_N > 0$ are the eigenvalues, and $\mathbf{v}_k$ are orthogonal eigenvectors representing discrete spatial Fourier modes.

Under continuous gradient descent with learning rate $\eta$, the error residual along eigenvector mode $\mathbf{v}_k$ evolves as:
$$e_k(t) = e_k(0) \exp\left( -2 \eta \lambda_k t \right)$$

This formula proves the **Frequency Principle**:
1. High-eigenvalue modes (which correspond to low spatial frequencies) decay exponentially fast with time constant $\tau_1 = \frac{1}{2\eta \lambda_1}$.
2. Low-eigenvalue modes (which correspond to high spatial frequencies) decay sluggishly with time constant $\tau_k = \frac{1}{2\eta \lambda_k} \gg \tau_1$.
3. When the ratio $\frac{\lambda_1}{\lambda_N} \gg 10^4$, the system suffers from extreme **spectral stiffness**, preventing standard networks from learning fine physical oscillations without Fourier feature embeddings or adaptive weights.

### 1.2 Spectral Bias & Fourier Error Decay

Let a physical target field be composed of multiple distinct spatial frequencies:
$$f(x) = \sin(2\pi x) + 0.4 \sin(8\pi x) + 0.15 \sin(32\pi x), \quad x \in [-1, 1]$$
- Carrier mode ($k = 1$, wavelength $\lambda = 1.0\text{ m}$)
- Mid-frequency mode ($k = 4$, wavelength $\lambda = 0.25\text{ m}$)

## 2. Computational Laboratory: Auditing Multi-Scale Target Data & Spectral Content

We audit the multiscale benchmark dataset `data/week2_multiscale_target.csv` to measure energy distribution across Fourier modes.

### 2.1 Python Implementation
```python
import pandas as pd
import numpy as np

def audit_multiscale_target():
    csv_path = "data/week2_multiscale_target.csv"
    df = pd.read_csv(csv_path)
    
    print("=== Multi-Scale Physical Target Audit ===")
    print(f"Loaded benchmark dataset: {csv_path}")
    print(f"Total sampled coordinate points: {len(df)}")
    print(f"Coordinate Span: x in [{df['x'].min():.2f}, {df['x'].max():.2f}]\n")
    
    # Compute Root-Mean-Square (RMS) Energy per Component
    rms_carrier = np.sqrt(np.mean(df['carrier_freq_2pi']**2))
    rms_mid = np.sqrt(np.mean(df['mid_freq_8pi']**2))
    rms_high = np.sqrt(np.mean(df['high_freq_32pi']**2))
    rms_total = np.sqrt(np.mean(df['target_signal']**2))
    
    print("Component Energy Partitioning:")
    print(f"  Carrier Mode (2 pi x)  : RMS = {rms_carrier:.4f} ({(rms_carrier/rms_total)*100:.1f}% energy)")
    print(f"  Mid Mode (8 pi x)      : RMS = {rms_mid:.4f} ({(rms_mid/rms_total)*100:.1f}% energy)")
    print(f"  High Mode (32 pi x)    : RMS = {rms_high:.4f} ({(rms_high/rms_total)*100:.1f}% energy)")
    print(f"  Total Composite Signal : RMS = {rms_total:.4f}")
    
    # Audit Discrete Fourier Transform (FFT) Power Spectrum
    N = len(df)
    fft_vals = np.fft.rfft(df['target_signal'].values)
    fft_freqs = np.fft.rfftfreq(N, d=(df['x'].iloc[1] - df['x'].iloc[0]))
    power_spectrum = (np.abs(fft_vals) / N)**2
    
    top_indices = np.argsort(power_spectrum)[-3:][::-1]
    print(f"\nTop 3 Dominant Fourier Modes Detected by FFT:")
    for rank, idx in enumerate(top_indices, 1):
        print(f"  Rank {rank}: Frequency = {fft_freqs[idx]:6.2f} Hz | Power = {power_spectrum[idx]:.6e}")

if __name__ == "__main__":
    audit_multiscale_target()
```

## 3. Daily Mastery Checkpoints

### Checkpoint 1: Parameter Count Calculation for an MLP
**Problem:** A coordinate PINN for 3D time-dependent Navier-Stokes takes inputs $(x, y, z, t) \in \mathbb{R}^4$ and outputs velocity and pressure $(u, v, w, p) \in \mathbb{R}^4$. The architecture consists of 5 hidden layers, each of width 128, with Tanh activations. Compute the exact total number of trainable parameters (weights and biases).  
**Solution:**
- Layer 1 (Input $\to$ Hidden 1):
  $$\mathbf{W}_1 \in \mathbb{R}^{4 \times 128} \implies 4 \times 128 = 512 \text{ weights}, \quad \mathbf{b}_1 \in \mathbb{R}^{128} \implies 128 \text{ biases. Subtotal: } 640$$
- Hidden Layers 2 to 5 (4 intermediate transformations of width $128 \to 128$):
  Each layer has $\mathbf{W}_l \in \mathbb{R}^{128 \times 128} \implies 128 \times 128 = 16,384 \text{ weights}, \quad \mathbf{b}_l \in \mathbb{R}^{128} \implies 128 \text{ biases}$.  
  Subtotal per layer: $16,384 + 128 = 16,512$.  
  For 4 layers: $4 \times 16,512 = 66,048$.
- Output Layer (Hidden 5 $\to$ Output):
  $$\mathbf{W}_{\mathrm{out}} \in \mathbb{R}^{128 \times 4} \implies 128 \times 4 = 512 \text{ weights}, \quad \mathbf{b}_{\mathrm{out}} \in \mathbb{R}^4 \implies 4 \text{ biases. Subtotal: } 516$$
- **Total Trainable Parameters:**
  $$P_{\mathrm{total}} = 640 + 66,048 + 516 = 67,204$$

### Checkpoint 2: Fourier Neural Feature Mapping
**Problem:** To overcome spectral bias, Tancik et al. (2020) proposed mapping coordinate $\mathbf{x} \in \mathbb{R}^d$ through random Fourier features: $\gamma(\mathbf{x}) = [\cos(2\pi \mathbf{B}\mathbf{x}), \sin(2\pi \mathbf{B}\mathbf{x})]^T$, where $\mathbf{B} \in \mathbb{R}^{m \times d}$ is sampled from $\mathcal{N}(0, \sigma_F^2)$. Show that the resulting kernel is stationary: $k(\mathbf{x}, \mathbf{x}') = h(\mathbf{x} - \mathbf{x}')$.  
**Solution:**
The inner product between mapped feature vectors is:
$$\gamma(\mathbf{x})^T \gamma(\mathbf{x}') = \sum_{j=1}^m \left[ \cos(2\pi \mathbf{b}_j^T \mathbf{x}) \cos(2\pi \mathbf{b}_j^T \mathbf{x}') + \sin(2\pi \mathbf{b}_j^T \mathbf{x}) \sin(2\pi \mathbf{b}_j^T \mathbf{x}') \right]$$
Using the trigonometric identity $\cos A \cos B + \sin A \sin B = \cos(A - B)$:
$$\gamma(\mathbf{x})^T \gamma(\mathbf{x}') = \sum_{j=1}^m \cos\left( 2\pi \mathbf{b}_j^T (\mathbf{x} - \mathbf{x}') \right)$$
Taking the expectation over the Gaussian distribution of $\mathbf{b}_j \sim \mathcal{N}(\mathbf{0}, \sigma_F^2 \mathbf{I})$:
$$\mathbb{E}[\cos(2\pi \mathbf{b}^T (\mathbf{x} - \mathbf{x}'))] = \exp\left( -2\pi^2 \sigma_F^2 \|\mathbf{x} - \mathbf{x}'\|_2^2 \right)$$
The expectation depends solely on the displacement vector $\mathbf{r} = \mathbf{x} - \mathbf{x}'$. By Bochner's Theorem, this defines a stationary Gaussian Radial Basis Function (RBF) kernel whose bandwidth $\sigma_F$ can be tuned to eliminate spectral bias at high frequencies.

### Checkpoint 3: Universal Approximation of Spatial Laplacians
**Problem:** Explain why Hornik, Stinchcombe, and White (1990) extended the Universal Approximation Theorem to derivatives ($C^m$ approximation), and state the condition required on the activation function.  
**Solution:**
Hornik et al. proved that if activation function $\sigma$ is non-constant, bounded, and belongs to $C^m(\mathbb{R})$, then multi-layer feedforward networks can simultaneously approximate a target function $f$ and all its partial derivatives up to order $m$ uniformly on compact sets:
$$\sup_{\mathbf{x} \in K} \left| D^\alpha u_\theta(\mathbf{x}) - D^\alpha f(\mathbf{x}) \right| < \epsilon, \quad \forall |\alpha| \le m$$
In scientific machine learning, this theorem provides the theoretical foundation ensuring that a neural network can approximate the differential operator $\mathcal{N}[u]$ (and not just the field $u$ itself), provided the activation function belongs to at least $C^m$.
