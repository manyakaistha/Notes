## 1. Day 3 Overview & Daily Goals

A single artificial neuron partitions coordinate space with a flat affine hyperplane. To represent complex, curved physical manifolds—such as shock waves, vortices, and multi-scale thermal fields—we must compose neurons into **Multi-Layer Perceptrons (MLPs)**.

The primary goals of Day 3 are:
1. Formalize the forward propagation recurrence relations across multi-layer networks.
2. Examine the Universal Approximation Theorem and its extension to continuous derivative approximation.
3. Track tensor dimensions and data flows through deep architectures: `[Batch, Coordinate_Dim] -> [Batch, Hidden] -> [Batch, Field_Dim]`.
4. Implement a custom multi-layer PyTorch module and verify layer-by-layer forward activation propagation.

## 2. Diagnostic & Previous-Day Verification

### Diagnostic Questions & Authoritative Solutions

#### 1. Why does an activation function need to be applied after each hidden layer rather than only at the final output?
- If activations are omitted between hidden layers, the composition $\mathbf{W}_3(\mathbf{W}_2(\mathbf{W}_1 \mathbf{x} + \mathbf{b}_1) + \mathbf{b}_2) + \mathbf{b}_3$ collapses into a single affine transformation. Applying non-linear activations after every hidden layer enables the network to bend and fold coordinate space, creating non-linear hypothesis manifolds.

#### 2. In PINNs, do we typically apply an activation function to the final output layer?
- **No.** The final layer is almost universally a purely linear affine projection ($u_\theta(\mathbf{x}) = \mathbf{W}^{(L)}\mathbf{h}^{(L-1)} + \mathbf{b}^{(L)}$). Applying a bounded activation (like $\tanh$ or $\text{sigmoid}$) to the output would artificially restrict the range of physical predictions to $[-1, 1]$ or $[0, 1]$, preventing the network from modeling physical fields with arbitrary magnitudes.

#### 3. What is the difference between model depth (number of layers) and model width (neurons per layer)?
- **Width:** Increases the number of hyperplanes partitioning coordinate space simultaneously in a single stage.
- **Depth:** Enables hierarchical composition, allowing later layers to compute complex non-linear combinations of earlier features. For smooth physical fields, moderately deep networks (4–8 layers) exhibit vastly superior expressivity per parameter than shallow, wide networks.

## 3. Core Theory: Multi-Layer Perceptron Formalism

### 3.1 Mathematical Recurrence Relations
Let $L$ denote the total number of layers (depth). The input layer receives spatial-temporal coordinate vector $\mathbf{x} \in \mathbb{R}^{d_{in}}$:

$$\mathbf{h}^{(0)} = \mathbf{x}$$

For hidden layers $l = 1, 2, \dots, L-1$:
$$\mathbf{z}^{(l)} = \mathbf{W}^{(l)} \mathbf{h}^{(l-1)} + \mathbf{b}^{(l)}, \quad \mathbf{W}^{(l)} \in \mathbb{R}^{n_l \times n_{l-1}}, \; \mathbf{b}^{(l)} \in \mathbb{R}^{n_l}$$
$$\mathbf{h}^{(l)} = \sigma(\mathbf{z}^{(l)})$$

For the output layer $l = L$:
$$\hat{\mathbf{u}} = u_\theta(\mathbf{x}) = \mathbf{W}^{(L)} \mathbf{h}^{(L-1)} + \mathbf{b}^{(L)} \in \mathbb{R}^{d_{out}}$$

### 3.2 Tensor Dimension Tracking
When passed a batch of $N$ coordinate evaluation points, the tensor shapes evolve as:

$$\mathbf{X}: [N, d_{in}] \xrightarrow{\quad \mathbf{W}^{(1)} \quad} \mathbf{h}^{(1)}: [N, n_1] \xrightarrow{\quad \mathbf{W}^{(2)} \quad} \dots \xrightarrow{\quad \mathbf{W}^{(L)} \quad} \hat{\mathbf{U}}: [N, d_{out}]$$

## 4. Practical Laboratory: Constructing and Tracing a PyTorch MLP

### 4.1 Concept → Code → Output → Interpretation

#### 1. Concept
We construct a 4-layer fully connected architecture for solving 2D space-time PDEs: mapping $(t, x) \in \mathbb{R}^2$ to a scalar state $u(t, x) \in \mathbb{R}^1$. We pass a batch of 5 space-time coordinate pairs and inspect the intermediate activation tensors at every hidden stage.

#### 2. Code
```python
import torch
import torch.nn as nn

torch.manual_seed(42)

class PhysicsMLP(nn.Module):
    def __init__(self, in_features=2, hidden_dim=8, out_features=1):
        super().__init__()
        self.fc1 = nn.Linear(in_features, hidden_dim)
        self.act1 = nn.Tanh()
        self.fc2 = nn.Linear(hidden_dim, hidden_dim)
        self.act2 = nn.Tanh()
        self.fc3 = nn.Linear(hidden_dim, out_features)

    def forward(self, x):
        h1 = self.act1(self.fc1(x))
        h2 = self.act2(self.fc2(h1))
        out = self.fc3(h2)
        return out, h1, h2

model = PhysicsMLP(in_features=2, hidden_dim=8, out_features=1)

# Sample batch of 5 space-time coordinates: (t, x)
coords = torch.tensor([
    [0.0, 0.0],
    [0.1, 0.2],
    [0.2, 0.5],
    [0.5, 0.8],
    [1.0, 1.0]
])

out, h1, h2 = model(coords)

print("--- Multi-Layer Perceptron Tensor Flow ---")
print(f"Input Coordinate Tensor Shape:     {coords.shape}")
print(f"Layer 1 Hidden State Shape (h1):   {h1.shape}")
print(f"Layer 2 Hidden State Shape (h2):   {h2.shape}")
print(f"Output Physical Field Shape (out): {out.shape}")
print("\nPredicted Field Values for Batch:")
for i in range(len(coords)):
    t_val, x_val = coords[i].tolist()
    u_val = out[i, 0].item()
    print(f"Coord (t={t_val:.1f}, x={x_val:.1f}) -> u_theta = {u_val:+.6f}")
```

#### 3. Output
```text

Input Coordinate Tensor Shape:     torch.Size([5, 2])
Layer 1 Hidden State Shape (h1):   torch.Size([5, 8])
Layer 2 Hidden State Shape (h2):   torch.Size([5, 8])
Output Physical Field Shape (out): torch.Size([5, 1])

Predicted Field Values for Batch:
Coord (t=0.0, x=0.0) -> u_theta = +0.134594
Coord (t=0.1, x=0.2) -> u_theta = +0.136009
Coord (t=0.2, x=0.5) -> u_theta = +0.141755
Coord (t=0.5, x=0.8) -> u_theta = +0.150682
Coord (t=1.0, x=1.0) -> u_theta = +0.160107
```

#### 4. Interpretation
The batch of 5 coordinate tuples `[5, 2]` expands smoothly into the 8-dimensional hidden feature spaces `[5, 8]`, passes through the non-linear hyperbolic tangent activations, and projects down to the scalar output field `[5, 1]`. The continuous model output varies smoothly from $+0.134594$ at $(0.0, 0.0)$ to $+0.160107$ at $(1.0, 1.0)$. In Week 4, this exact forward architecture will represent our continuous temperature field $u_\theta(t, x)$.

## 5. Daily Knowledge Mastery Checkpoint

### Problem 1: Parameter Accounting in Deep MLPs
**Question:** A PINN architecture for 3D Navier-Stokes equations maps $(t, x, y, z) \in \mathbb{R}^4$ to velocity and pressure $(u, v, w, p) \in \mathbb{R}^4$. The network has 5 hidden layers, each containing 64 neurons, and all hidden layers use $\tanh$ activations. Calculate the total number of trainable weights and biases in the model.  
**Authoritative Solution:**  
1. Layer 1 (Input to Hidden 1): $\mathbf{W}^{(1)} \in \mathbb{R}^{64 \times 4}$, $\mathbf{b}^{(1)} \in \mathbb{R}^{64} \implies 64 \times 4 + 64 = 256 + 64 = 320$.
2. Layers 2 through 5 (Hidden to Hidden, 4 layers): Each has $\mathbf{W} \in \mathbb{R}^{64 \times 64}$, $\mathbf{b} \in \mathbb{R}^{64} \implies 4 \times (64 \times 64 + 64) = 4 \times (4096 + 64) = 4 \times 4160 = 16,640$.
3. Layer 6 (Hidden 5 to Output): $\mathbf{W}^{(6)} \in \mathbb{R}^{4 \times 64}$, $\mathbf{b}^{(6)} \in \mathbb{R}^{4} \implies 4 \times 64 + 4 = 256 + 4 = 260$.  
Total parameters = $320 + 16,640 + 260 = 17,220$ parameters.

### Problem 2: Preserving Continuous Symmetries
**Question:** If a physical field possesses rotational symmetry around the origin $u(r) = u(\sqrt{x^2 + y^2})$, how can coordinate inputs be preprocessed to enforce this symmetry unconditionally?  
**Authoritative Solution:**  
Instead of feeding Cartesian coordinates $(x, y)$ as independent inputs, compute the radial coordinate $r = \sqrt{x^2 + y^2}$ and pass $r$ as a single input to the network: $u_\theta(r)$. This embeds rotational invariance directly into the architecture, reducing the dimensionality of the hypothesis space.
