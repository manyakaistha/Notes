## 1. Day 3 Overview & Daily Goals

In traditional engineering simulation (CFD, FEA), up to 80% of human engineering time is consumed by **mesh generation**—partitioning complex 3D aerodynamic surfaces or biological vessels into millions of conforming tetrahedral or hexahedral elements. Physics-Informed Neural Networks eliminate this bottleneck entirely by operating on **collocation points**.

The primary goals of Day 3 are:
1. Define collocation points as uncoupled spatial-temporal evaluation sites for physical conservation laws.
2. Compare the four primary sampling strategies: Uniform Grid, Pseudo-Random Monte Carlo, Latin Hypercube Sampling (LHS), and Residual-Adaptive Distribution (RAD).
3. Quantify space-filling metrics (minimum inter-point distance, discrepancy).
4. Implement an efficient Latin Hypercube Sampler in Python.

## 2. Diagnostic & Previous-Day Verification

### Diagnostic Questions & Authoritative Solutions

#### 1. What is the fundamental difference between a finite element mesh node and a PINN collocation point?
- A mesh node is part of a topologically connected graph: it requires element connectivity, edge adjacency lists, shape function integrals, and neighbor communication stencils.
- A collocation point is completely unconnected: it is simply an isolated coordinate tuple $\mathbf{x}_i \in \mathbb{R}^d$ where the neural network and its autodiff derivatives are evaluated independently.

#### 2. Why does uniform random sampling perform poorly in multi-dimensional domain sampling?
- Pure uniform random sampling (pseudo-random numbers) naturally exhibits **Poisson clustering**: points randomly clump together in some spatial regions while leaving large empty voids in others. In a PINN, empty voids mean the differential equation is completely unconstrained in those subdomains.

#### 3. How does Latin Hypercube Sampling (LHS) prevent spatial clustering?
- LHS is a stratified sampling technique. It divides each dimension into $N$ equal bins and places exactly one sample per hyperplane, ensuring that the 1D projection onto every coordinate axis is uniformly distributed while maintaining random multi-dimensional combinations.

## 4. Practical Laboratory: Implementing Latin Hypercube Sampling

### 4.1 Concept → Code → Output → Interpretation

#### 1. Concept
We implement a Latin Hypercube Sampler for a 2D space-time domain $(t, x) \in [0, 1] \times [0, 1]$ and compare its minimum inter-point distance against standard uniform random sampling for $N=50$ points. A larger minimum inter-point distance indicates superior space-filling properties without clustering.

#### 2. Code
```python
import numpy as np

rng = np.random.default_rng(42)

def latin_hypercube_2d(n_samples, rng):
    # Divide each axis into n_samples intervals
    result = np.empty((n_samples, 2))
    for dim in range(2):
        perm = rng.permutation(n_samples)
        # Stratified jitter within each bin
        result[:, dim] = (perm + rng.uniform(0, 1, n_samples)) / n_samples
    return result

N = 50

# 1. Random Uniform Sampling
pts_random = rng.uniform(0, 1, size=(N, 2))

# 2. Latin Hypercube Sampling
pts_lhs = latin_hypercube_2d(N, rng)

# Compute minimum inter-point Euclidean distance (clustering metric)
def min_distance(pts):
    diffs = pts[:, np.newaxis, :] - pts[np.newaxis, :, :]
    dist_matrix = np.linalg.norm(diffs, axis=-1)
    np.fill_diagonal(dist_matrix, np.inf)
    return np.min(dist_matrix)

min_dist_rand = min_distance(pts_random)
min_dist_lhs = min_distance(pts_lhs)

print(f"Number of Collocation Points: {N}")
print(f"Random Sampling Min Distance: {min_dist_rand:.6f}")
print(f"LHS Sampling Min Distance:    {min_dist_lhs:.6f}")
print(f"Space-Filling Improvement:    {((min_dist_lhs - min_dist_rand) / min_dist_rand) * 100:.1f}%")
```

#### 3. Output
```text
Number of Collocation Points: 50
Random Sampling Min Distance: 0.012586
LHS Sampling Min Distance:    0.038104
Space-Filling Improvement:    202.8%
```

#### 4. Interpretation
In pure random sampling, random pairs of points land within $0.012586$ units of each other, creating wasted redundant evaluations while leaving voids elsewhere. Latin Hypercube Sampling increases the minimum inter-point spacing to $0.038104$—a **$202.8\%$ increase in spatial separation**. This guarantees that the governing differential equation is enforced uniformly across the domain without empty gaps.

## 5. Daily Knowledge Mastery Checkpoint

### Problem 1: Residual-Adaptive Distribution (RAD)
**Question:** Explain how Residual-Adaptive Distribution (RAD) works in PINN training and why it is essential for shock-capturing PDEs like viscous Burgers' equation.  
**Authoritative Solution:**  
In RAD, training begins with a baseline set of collocation points (e.g., via LHS). Every $K$ epochs, the network evaluates the PDE residual magnitude $|\mathcal{R}(\mathbf{x})|$ across a dense candidate pool of domain points. A probability density function is constructed proportional to the residual magnitude:
$$p(\mathbf{x}) \propto \frac{|\mathcal{R}(\mathbf{x})|^k}{\sum |\mathcal{R}(\mathbf{x}_j)|^k}$$
New collocation points are resampled according to $p(\mathbf{x})$, concentrating points along steep shock fronts and boundary layers where physics violations are concentrated, while thinning points in smooth, quiescent regions.

### Problem 2: Domain vs. Boundary Partitioning
**Question:** A PINN is trained on domain $\Omega = [0, 1] \times [0, 1]$ with time $t \in [0, 1]$. How should the total training point budget $N_{\text{total}} = 5000$ be allocated among interior collocation points $N_f$, initial condition points $N_0$, and boundary condition points $N_b$?  
**Authoritative Solution:**  
A standard empirical heuristic in scientific machine learning allocates:
- **Interior PDE Collocation Points ($N_f$):** $60\% - 80\%$ (e.g., $N_f = 3500$ points) to resolve the volume/area physics across space-time.
- **Initial Condition Points ($N_0$ at $t=0$):** $10\% - 20\%$ (e.g., $N_0 = 500$ points) to firmly anchor the Cauchy initial value state.
- **Boundary Condition Points ($N_b$ along $\partial\Omega$):** $10\% - 20\%$ (e.g., $N_b = 1000$ points, partitioned evenly across the 4 spatial domain walls).
