## 1. Day 4 Overview & Daily Goals

In standard supervised learning, the loss function measures the discrepancy between model predictions and external ground truth labels ($y_i - \hat{y}_i$). In Physics-Informed Neural Networks, external labels are replaced by the **Physics Residual Operator** $\mathcal{R}(\mathbf{x}; \theta)$.

The primary goals of Day 4 are:
1. Define the continuous physics residual operator $\mathcal{R}(\mathbf{x}; \theta) \equiv \mathcal{N}[u_\theta](\mathbf{x}) - f(\mathbf{x})$.
2. Trace the computational flow of the residual through PyTorch's automatic differentiation engine.
3. Formulate the mean squared residual loss functional $\mathcal{L}_{\mathrm{pde}}(\theta) = \frac{1}{N_f} \sum \|\mathcal{R}(\mathbf{x}_i; \theta)\|^2$.
4. Implement a complete residual evaluation routine and track its numerical magnitude.

## 2. Diagnostic & Previous-Day Verification

### Diagnostic Questions & Authoritative Solutions

#### 1. What does a physics residual value of $\mathcal{R}(\mathbf{x}) = 0$ signify?
- It signifies that at coordinate $\mathbf{x}$, the candidate neural network solution $u_\theta$ satisfies the governing physical conservation law (mass, momentum, energy) exactly. If $\mathcal{R}(\mathbf{x}) = 0$ everywhere on continuous domain $\Omega$ and satisfies boundary conditions, $u_\theta$ is the exact physical solution.

#### 2. Why does the physics residual act as a "self-supervised" loss?
- Because evaluating $\mathcal{R}(\mathbf{x})$ requires **no ground-truth physical measurements $y$**. The loss is generated entirely from the mathematical consistency of the network's own coordinate derivatives with the physical governing equation.

#### 3. Why must we square the residual rather than simply taking its mean?
- If we minimized the simple mean $\frac{1}{N}\sum \mathcal{R}(\mathbf{x}_i)$, large positive physical violations in one region would cancel out large negative physical violations in another, yielding an overall zero loss while violating physics everywhere. Minimizing the mean squared norm $\frac{1}{N}\sum \|\mathcal{R}(\mathbf{x}_i)\|^2$ forces the residual to approach zero point-wise everywhere.

## 3. Core Theory: The Residual Functional Formulation

Let the general differential equation be expressed as:

$$\mathcal{N}[u](\mathbf{x}) = f(\mathbf{x}), \quad \mathbf{x} \in \Omega$$

For a parameterized neural surrogate $u_\theta(\mathbf{x})$, the residual field is:

$$\mathcal{R}(\mathbf{x}; \theta) = \mathcal{N}[u_\theta](\mathbf{x}) - f(\mathbf{x})$$

### Canonical Differential Operators:
1. **Damped Harmonic Oscillator (ODE):**
   $$\mathcal{R}(t; \theta) = m \frac{d^2 u_\theta}{dt^2} + c \frac{du_\theta}{dt} + k u_\theta$$
2. **1D Heat Diffusion (PDE):**
   $$\mathcal{R}(t, x; \theta) = \frac{\partial u_\theta}{\partial t} - \alpha \frac{\partial^2 u_\theta}{\partial x^2}$$
3. **Viscous Burgers' Shock Equation (Non-linear PDE):**
   $$\mathcal{R}(t, x; \theta) = \frac{\partial u_\theta}{\partial t} + u_\theta \frac{\partial u_\theta}{\partial x} - \nu \frac{\partial^2 u_\theta}{\partial x^2}$$

## 4. Practical Laboratory: Evaluating the ODE Residual Field

### 4.1 Concept → Code → Output → Interpretation

#### 1. Concept
We construct a small neural network $u_\theta(t)$ initialized with random weights. We sample $N=5$ collocation points $t \in [0, 1]$, compute the first derivative $\frac{du}{dt}$ and second derivative $\frac{d^2u}{dt^2}$ via autodiff, and evaluate the harmonic oscillator residual $\mathcal{R}(t) = \ddot{u} + 2\dot{u} + 20u$ and its mean squared loss $\mathcal{L}_{\mathrm{ode}}$.

#### 2. Code
```python
import torch
import torch.nn as nn

torch.manual_seed(42)

# Oscillator network: t -> u
net = nn.Sequential(
    nn.Linear(1, 16),
    nn.Tanh(),
    nn.Linear(16, 1)
)

# Collocation points with gradient tracking
t_colloc = torch.linspace(0.0, 1.0, 5, requires_grad=True).unsqueeze(1)

# Primary Forward Pass
u = net(t_colloc)

# 1st Derivative: du/dt
u_t = torch.autograd.grad(
    u, t_colloc, torch.ones_like(u), create_graph=True
)[0]

# 2nd Derivative: d2u/dt2
u_tt = torch.autograd.grad(
    u_t, t_colloc, torch.ones_like(u_t), create_graph=True
)[0]

# Physical parameters: m=1.0, mu=2.0, k=20.0
# Governing equation: u_tt + 2*u_t + 20*u = 0
residual = u_tt + 2.0 * u_t + 20.0 * u

# Physics Loss
loss_ode = torch.mean(residual**2)

print(f"{'Time t':<10} | {'Surrogate u':<14} | {'Velocity u_t':<14} | {'Accel u_tt':<14} | {'Residual R':<14}")
print("-" * 72)
for i in range(len(t_colloc)):
    t_v = t_colloc[i, 0].item()
    u_v = u[i, 0].item()
    ut_v = u_t[i, 0].item()
    utt_v = u_tt[i, 0].item()
    r_v = residual[i, 0].item()
    print(f"{t_v:<10.2f} | {u_v:<14.4f} | {ut_v:<14.4f} | {utt_v:<14.4f} | {r_v:<14.4f}")

print("-" * 72)
print(f"Mean Squared Physics Loss (L_ode): {loss_ode.item():.4f}")
```

#### 4. Interpretation
At initialization, the random neural network predicts $u(0) \approx 0.3982$. When substituted into the differential operator $\ddot{u} + 2\dot{u} + 20u$, the residual evaluates to $R \approx -0.0903 + 2(0.1691) + 20(0.3982) \approx 8.2120$. Across all 5 collocation points, the mean squared physics loss evaluates to $86.4258$. This scalar provides the exact quantitative signal that backpropagation will minimize to warp the network's weights toward the true physical dynamics.

## 5. Daily Knowledge Mastery Checkpoint

### Problem 1: Non-linear Advection Derivative
**Question:** In the viscous Burgers' equation $\partial_t u + u \partial_x u = \nu \partial_{xx} u$, explain why the non-linear advection term $u \frac{\partial u}{\partial x}$ is trivial for a PINN to evaluate compared to classical numerical finite difference schemes.  
**Authoritative Solution:**  
In classical finite differences, the non-linear term $u \frac{\partial u}{\partial x}$ creates quadratic matrix coupling that requires iterative Newton-Raphson solvers at every time step, and non-conservative stencils trigger numerical instabilities (aliasing, artificial oscillations). In a PINN, $u$ is simply the network output tensor and $\frac{\partial u}{\partial x}$ is evaluated point-wise via autodiff. The product $u \odot \frac{\partial u}{\partial x}$ is computed by simple element-wise tensor multiplication, requiring no linear system inversion or stabilization stencils.

### Problem 2: Computational Memory Scaling
**Question:** How does the memory footprint of storing the computational graph scale when computing a third-order derivative $\frac{\partial^3 u}{\partial x^3}$ versus a first-order derivative $\frac{\partial u}{\partial x}$?  
**Authoritative Solution:**  
Each successive derivative requires an additional backward autodiff graph traversal with `create_graph=True`. The memory footprint scales roughly linearly with the derivative order $k$ (roughly $k$ times the forward activation memory), because PyTorch must retain intermediate computational graphs for all lower-order derivative operations.
