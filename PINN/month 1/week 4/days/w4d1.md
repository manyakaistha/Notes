## 2. Prerequisite Diagnostic Checkpoint

### Diagnostic Questions & Authoritative Solutions

#### 1. Why must the collocation point tensor have `requires_grad=True`?
- To compute derivatives of the network's output with respect to coordinates ($\frac{\partial u}{\partial t}$, $\frac{\partial u}{\partial x}$), the input coordinate tensor must be a leaf node in the autograd computation graph with gradient tracking enabled. If `requires_grad=False`, calling `torch.autograd.grad` with inputs as the coordinate tensor will raise a runtime error.

#### 2. What is the danger of evaluating boundary loss on interior collocation points?
- Boundary conditions (Dirichlet, Neumann) are defined strictly on the spatial-temporal boundary $\partial\Omega$ or $t=0$. Enforcing boundary values at interior points over-constrains the problem and contradicts the differential equation, causing training to diverge or produce unphysical artifacts.

#### 3. Why is an analytical ground-truth baseline essential during PINN development?
- In scientific computing, a network may converge to a low loss value while learning a non-physical solution (e.g., due to boundary weight imbalance or spectral bias). Comparing predictions against an analytical baseline verifies that the implementation is mathematically sound before applying it to problems with unknown solutions.

## 3. Core Theory: Geometric Specification & Collocation Assembly

```
Continuous Geometry Ω = [0, 1]
├── Interior Domain Ω_interior: t in (0, 1] ───> Collocation Set T_f (N_f points via LHS)
└── Initial Boundary t = 0                 ───> Initial Point T_0 (N_0 points at origin)
```

For the damped harmonic oscillator:
$$m \ddot{u} + \mu \dot{u} + k u = 0, \quad t \in [0, 1]$$
$$u(0) = 1.0, \quad \dot{u}(0) = 0.0$$
with analytical benchmark:
$$u_{\text{exact}}(t) = e^{-\gamma t} \left( \cos(\omega_d t) + \frac{\gamma}{\omega_d} \sin(\omega_d t) \right)$$
where $\gamma = \frac{\mu}{2m} = 1.0$ and $\omega_d = \sqrt{k/m - \gamma^2} = \sqrt{19} \approx 4.3589\text{ rad/s}$.

## 4. Practical Laboratory: Geometry Setup & LHS Collocation Generation

### 4.1 Concept → Code → Output → Interpretation

#### 1. Concept
We implement a robust PyTorch data generation module that samples $N_f = 40$ interior collocation points via Latin Hypercube Sampling, creates the initial boundary tensor at $t=0$, and evaluates the exact analytical benchmark across a dense evaluation grid.

#### 2. Code
```python
import torch
import numpy as np

# 1. Physical parameters
m, mu, k = 1.0, 2.0, 20.0
gamma = mu / (2.0 * m)
omega_d = np.sqrt(k / m - gamma**2)

# 2. Latin Hypercube Collocation Generator
def generate_lhs_collocation(n_pts, t_min=0.0, t_max=1.0, seed=42):
    rng = np.random.default_rng(seed)
    bins = np.linspace(t_min, t_max, n_pts + 1)
    pts = bins[:-1] + rng.uniform(0, 1, n_pts) * (bins[1:] - bins[:-1])
    # Convert to PyTorch tensor with gradient tracking
    t_tensor = torch.tensor(pts, dtype=torch.float32, requires_grad=True).unsqueeze(1)
    return t_tensor

# Generate N_f = 40 points
t_colloc = generate_lhs_collocation(40)

# Initial condition tensor at t=0
t_initial = torch.tensor([[0.0]], dtype=torch.float32, requires_grad=True)

# 3. Analytical baseline evaluator
def exact_solution(t_tensor):
    t_np = t_tensor.detach().numpy()
    return np.exp(-gamma * t_np) * (np.cos(omega_d * t_np) + (gamma / omega_d) * np.sin(omega_d * t_np))

u_exact_initial = exact_solution(t_initial)

print(f"Collocation Tensor Shape: {t_colloc.shape} (requires_grad={t_colloc.requires_grad})")
print(f"Initial Tensor Shape:     {t_initial.shape} (requires_grad={t_initial.requires_grad})")
print(f"Analytical State at t=0:  {u_exact_initial.item():.6f}")
print(f"Collocation Range: [{t_colloc.min().item():.4f}, {t_colloc.max().item():.4f}]")
print(f"First 5 Collocation Points:\n{t_colloc[:5].squeeze().tolist()}")
```

#### 3. Output
```text
Collocation Tensor Shape: torch.Size([40, 1]) (requires_grad=True)
Initial Tensor Shape:     torch.Size([1, 1]) (requires_grad=True)
Analytical State at t=0:  1.000000
Collocation Range: [0.0193, 0.9984]
First 5 Collocation Points:
[0.01934988610446453, 0.03846695274114609, 0.07147321105003357, 0.08053896576166153, 0.10427387058734894]
```

#### 4. Interpretation
The LHS generator partitions the interval $[0, 1]$ into 40 non-overlapping bins and stratifies points within each bin, guaranteeing full space-filling coverage from $0.0193$ to $0.9984$ without clustering. Both tensors are equipped with `requires_grad=True`, establishing them as active leaf nodes ready for automatic differentiation. The exact analytical solution confirms $u(0) = 1.000000$.

## 5. Daily Knowledge Mastery Checkpoint

### Problem 1: Tensor Shape Consistency in Multi-Dimensional PDEs
**Question:** For a 2D space-time PDE $(t, x) \in [0, 1] \times [-1, 1]$, write down the PyTorch code to construct the initial condition tensor at $t=0$ across $N_0 = 100$ spatial points.  
**Authoritative Solution:**  
```python
x_vals = torch.linspace(-1.0, 1.0, 100).unsqueeze(1)
t_vals = torch.zeros_like(x_vals)
# Concatenate into shape [100, 2] with requires_grad=True
coords_initial = torch.cat([t_vals, x_vals], dim=1).requires_grad_()
```

### Problem 2: Boundary Point Tensor Assembly
**Question:** For the same domain, what are the tensor coordinates and shapes for the left boundary $x=-1$ and right boundary $x=+1$ across $N_b = 50$ time steps?  
**Authoritative Solution:**  
```python
t_steps = torch.linspace(0.0, 1.0, 50).unsqueeze(1)
x_left = torch.full_like(t_steps, -1.0)
x_right = torch.full_like(t_steps, 1.0)

coords_bc_left = torch.cat([t_steps, x_left], dim=1).requires_grad_()   # Shape [50, 2]
coords_bc_right = torch.cat([t_steps, x_right], dim=1).requires_grad_() # Shape [50, 2]
```
