## 1. Day 3 Overview & Daily Goals

A PINN is fundamentally a multi-task learning system. If the loss weighting hyperparameters $\lambda_{\mathrm{pde}}, \lambda_{\mathrm{bc}}, \lambda_{\mathrm{ic}}$ are chosen improperly, the network will satisfy one term while completely ignoring the others.

The primary goals of Day 3 are:
1. Implement modular loss functions for interior differential residuals, Dirichlet boundary conditions, and initial Cauchy states.
2. Establish empirical rules for tuning loss hyper-weights ($\lambda_{\mathrm{ic}}, \lambda_{\mathrm{bc}}$).
3. Track and visualize the simultaneous decay of individual loss components.
4. Implement a clean, modular loss manager class in PyTorch.

## 2. Prerequisite Diagnostic Checkpoint

### Diagnostic Questions & Authoritative Solutions

#### 1. Why is the initial condition penalty weight often set higher than the interior PDE residual weight ($\lambda_{\mathrm{ic}} \gg \lambda_{\mathrm{pde}}$)?
- Initial conditions anchor the physical trajectory at $t=0$. If the network misses the starting point, even a perfectly satisfied differential equation will integrate along the wrong characteristic trajectory, accumulating massive downstream errors. Setting $\lambda_{\mathrm{ic}} \in [10, 50]$ forces the optimizer to rigidly anchor the initial state early in training.

#### 2. How is a Neumann boundary condition $\frac{\partial u}{\partial n} = g$ implemented in the loss functional?
- For an outward normal vector $\mathbf{n}$, the directional derivative $\nabla u_\theta \cdot \mathbf{n}$ is evaluated at the boundary coordinates using autodiff. The loss penalty is the mean squared error:
  $$\mathcal{L}_{\text{neumann}} = \frac{1}{N_b} \sum_{i=1}^{N_b} \left( \nabla u_\theta(\mathbf{x}_b^{(i)}) \cdot \mathbf{n} - g(\mathbf{x}_b^{(i)}) \right)^2$$

#### 3. What happens if $\lambda_{\mathrm{ic}}$ is set excessively high (e.g., $10^6$)?
- The Hessian of the loss becomes severely ill-conditioned. Gradients from $\mathcal{L}_{\mathrm{ic}}$ dwarf $\mathcal{L}_{\mathrm{pde}}$ by six orders of magnitude, causing the optimizer to satisfy the initial condition while making zero progress on the differential equation (gradient stiffness).

## 4. Practical Laboratory: Multi-Component Loss Tracking

### 4.1 Concept → Code → Output → Interpretation

#### 1. Concept
We construct a modular loss manager for the damped oscillator ($m=1.0, \mu=2.0, k=20.0$), initialize an MLP, and train for 150 Adam iterations with $\lambda_{\mathrm{ic}} = 20.0$. We log individual loss components at milestones to observe multi-objective convergence.

#### 2. Code
```python
import torch
import torch.nn as nn

torch.manual_seed(42)

# Neural network architecture
pinn = nn.Sequential(
    nn.Linear(1, 32),
    nn.Tanh(),
    nn.Linear(32, 32),
    nn.Tanh(),
    nn.Linear(32, 1)
)

opt = torch.optim.Adam(pinn.parameters(), lr=0.01)

# Training points
t_c = torch.linspace(0.0, 1.0, 40, requires_grad=True).unsqueeze(1)
t_0 = torch.tensor([[0.0]], requires_grad=True)

lambda_ic = 20.0

print(f"{'Epoch':<6} | {'Total Loss':<14} | {'ODE Loss':<14} | {'IC Disp Loss':<14} | {'IC Vel Loss':<14}")
print("-" * 72)

for epoch in range(1, 151):
    opt.zero_grad()

    # 1. Interior ODE Loss
    u_c = pinn(t_c)
    u_t = torch.autograd.grad(u_c, t_c, torch.ones_like(u_c), create_graph=True)[0]
    u_tt = torch.autograd.grad(u_t, t_c, torch.ones_like(u_t), create_graph=True)[0]
    res = u_tt + 2.0 * u_t + 20.0 * u_c
    l_ode = torch.mean(res**2)

    # 2. Initial Condition Loss: u(0)=1, u'(0)=0
    u_0 = pinn(t_0)
    u_0_t = torch.autograd.grad(u_0, t_0, torch.ones_like(u_0), create_graph=True)[0]
    l_ic_disp = (u_0 - 1.0)**2
    l_ic_vel = (u_0_t - 0.0)**2
    l_ic = l_ic_disp + l_ic_vel

    # Total weighted loss
    total = l_ode + lambda_ic * l_ic
    total.backward()
    opt.step()

    if epoch in [1, 25, 50, 100, 150]:
        print(f"{epoch:<6d} | {total.item():<14.5f} | {l_ode.item():<14.5f} | {l_ic_disp.item():<14.5f} | {l_ic_vel.item():<14.5f}")
```

#### 4. Interpretation
In early epochs, the unweighted initial velocity error is large ($0.93202$). Because $\lambda_{\mathrm{ic}} = 20.0$ amplifies this penalty, the optimizer steadily reduces the displacement error from $0.36214$ to $0.01201$ and velocity error to $0.17738$. By epoch 150, the total loss has fallen from $43.177$ to $4.892$, setting the stage for fine-tuning.

## 5. Daily Knowledge Mastery Checkpoint

### Problem 1: Balancing Diverging Losses
**Question:** If training logs reveal that $\mathcal{L}_{\mathrm{pde}}$ is decreasing while $\mathcal{L}_{\mathrm{bc}}$ is increasing, what is happening physically, and how should hyperparameters be adjusted?  
**Authoritative Solution:**  
The network is relaxing its boundary constraints to satisfy the interior differential equation more easily (or drifting toward the trivial zero solution). The boundary penalty weight $\lambda_{\mathrm{bc}}$ must be increased by a factor of $5\times - 10\times$, or dynamic learning rate annealing must be enabled to restore balance.

### Problem 2: Robin Boundary Loss Formulation
**Question:** Write the loss penalty for a Robin boundary condition $k \frac{\partial u}{\partial x} + h u = q_0$ at $x=1.0$.  
**Authoritative Solution:**  
```python
u_x_b = DifferentialEngine.grad(u_b, x_b)
robin_residual = k * u_x_b + h * u_b - q0
loss_robin = torch.mean(robin_residual**2)
```
