# Feature Map

A feature map (or activation map) is the spatial output tensor $\mathbf{Y} \in \mathbb{R}^{H' \times W'}$ generated by applying a specific convolutional kernel $\mathbf{K}$ followed by an element-wise non-linear activation function $\sigma(\cdot)$ (such as ReLU) across an input image or preceding layer:
$$\mathbf{Y} = \sigma(\mathbf{X} * \mathbf{K} + b)$$
In a multi-channel convolutional layer with $C_{out}$ distinct filters, the collection of feature maps forms a third-order tensor $\mathbf{Y} \in \mathbb{R}^{C_{out} \times H' \times W'}$.

Each distinct feature map represents the spatial response landscape for a specific learned pattern. Early-layer feature maps isolate elementary geometric primitives such as oriented edges (Sobel-like responses), color gradients, and high-frequency textures. Intermediate and deeper feature maps combine these primitives hierarchically into part-based detectors (corners, curves, circular motifs) and object-level semantic embeddings.

**Why it matters here:** Deep convolutional feature maps compress spatial dimensions while expanding channel capacity, culminating in a global embedding vector. In contrast, Vision Transformers discard the continuous 2D feature map hierarchy in favor of discrete sequence tokens mapped through self-attention layers.
